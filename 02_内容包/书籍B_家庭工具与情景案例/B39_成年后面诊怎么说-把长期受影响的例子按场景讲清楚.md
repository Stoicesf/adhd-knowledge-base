# 成年后面诊怎么说：把长期受影响的例子按场景讲清楚

> 本页写给准备成年后第一次评估、不知道面诊时怎么开口的你。面诊前先整理哪些材料，见 [成年后第一次想评估自己：先整理哪些材料](../书籍A_公开知识库/A07_成年后第一次想评估自己-先整理哪些材料.md)；一次评估大致经过哪些环节，见 [一次评估大致怎么走：可能经历的流程与等待](../书籍A_公开知识库/A08_一次评估大致怎么走-流程与等待.md)。**本页不提供自评量表、不复述量表题目与评分标准，也不作自我诊断依据。**

## 今天能做的 3 件事

1. **面诊前一晚，按童年、上学、工作、家务四个场景，各写一个具体例子。** 每个例子写清时间、场景、当时发生了什么、大概多久出现一次。
2. **面诊开口先说明："我想按几个生活场景，讲几件长期受影响的事。"** 让医生知道你有结构，而不是想到哪说到哪。
3. **不拿网上自测分数给自己下结论。** 分数只作为"是否需要进一步评估"的参考，是不是、是什么，由专科评估判断。

## 为什么这样做有效

成年阶段的困难常常已经换了外壳：不是小时候的"坐不住"，而是开会跑神、任务漏接、家务堆着、约定时间对不上。医生需要的不是一句"我注意力不好"，而是**跨场景、长期反复的具体例子**：场合、频率、影响。

按场景讲，是把模糊感受拆成医生可以逐条核对的材料；讲得越具体，评估越容易对准方向。

本页只帮你组织陈述方式，不替你判断；是否需要评估，由专科人员按流程判断。

## 具体怎么做

### 一、四个场景各写一个例子（可打印填空）

| 场景 | 例子要写清什么 | 可照念的开头句 |
|---|---|---|
| 童年（小学前后） | 当时在什么场合、被老师或家人反复提醒过什么、持续了多久 | "小时候在课堂上，我经常……，老师和家人提醒过我很多次。" |
| 上学阶段 | 听课、作业、考试、和同学相处上反复出现的困难 | "上学期间，在写作业和听课上，我常常……，一直到毕业都还在。" |
| 工作以后 | 开会、接任务、时间安排、和同事协作上反复出现的情况 | "工作以后，我在……这件事上反复出现……，已经影响到日常完成任务。" |
| 家务与生活 | 家务、记账、约定时间、日常琐事上的反复困难 | "在家里，我经常……，家里人也提过不止一次。" |

### 二、陈述时按这个顺序走

1. **先说跨度**：这些情况从什么时候开始、持续到现在，是一直有还是时轻时重。
2. **逐个场景举例**：每个场景先说具体事实（时间、地点、次数），再说对你的影响，不急着下结论。
3. **讲身边人观察到的情况**：家人、伴侣或同事提醒过你的，一并转述，不替他们评价。
4. **最后说你这次来想弄清什么**：例如"我想了解这些长期反复的困难，需不需要进一步评估"。

### 三、两个可以直接照念的句子

> "我不是今天才出问题，这些情况从上学时候就断断续续有，工作以后在任务安排和日常琐事上也反复出现。"

> "我今天想按童年、上学、工作、家务几个场景，各讲一件具体的事；这些是我自己和身边人观察到的情况，是不是需要进一步评估，想请您判断。"

### 第一周对照清单

- ☐ 四个场景各写了一个具体例子，有时间、场景和频率
- ☐ 例子里写的是事实和影响，没有给自己贴诊断标签
- ☐ 没有把网上自测分数当成结论念给医生
- ☐ 开口顺序是：跨度 → 分场景举例 → 他人观察 → 这次想弄清什么

**做对了的标志**：面诊时你能按场景把例子讲完，不被情绪带着跑；医生问"还有别的场景吗"，你能补上另一件具体的事；离开时你清楚下一步评估要走什么流程。

## 常见误区

| 误区 | 实际 |
|---|---|
| "我把网上自测分数念给医生，就能算诊断依据" | 自测只是筛查参考；本页不提供量表、不作自我诊断依据，结论由专科评估给出 |
| "面诊只讲最近最糟的一次就行" | 医生需要跨场景、长期反复的例子；单次事件不足以说明长期情况 |
| "把感受形容得越严重越好" | 具体事实和频率比形容词有用；评价词需要医生自己核对 |
| "我应该替自己先下一个判断" | 你的任务是把例子讲清楚，判断由专科人员按流程做 |

> 本页提供的是教育与自我管理信息，不构成诊断或治疗建议。是否需要进一步评估，请与有处方权的医生或儿童精神科/心理科专业人员讨论。

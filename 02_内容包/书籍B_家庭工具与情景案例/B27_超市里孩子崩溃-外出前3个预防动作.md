# 超市里孩子崩溃：外出前的 3 个预防动作

> 本页只解决一件事：**进超市之前，你能提前做哪 3 个动作，让今天这次外出不太容易崩。** 它不写崩溃当场怎么收场（那是另一件事），也不重复早晨出门的固定顺序（见 [学前早晨出门总拖](B19_学前早晨出门总拖-出门前固定顺序.md)）和家里写作业的环境调整（见 [写作业频繁离座](B01_写作业频繁离座-家庭环境调整的5个具体动作.md)）。

## 今天能做的 3 件事

1. **出门前和孩子一起写一张"这次只买 3 样"的购物清单**，让他用画或贴纸参与，到了超市照着找。
2. **在车上或楼下，和孩子约定一个"人多就走"的暗号**——比如你摸一下耳朵，意思是"我们先出去透气"。
3. **包里固定放一个降刺激小物**（一副耳罩 / 一个捏捏乐 / 一瓶他熟悉的水），人一多就拿出来。

## 为什么这样做有效

超市对 ADHD 孩子来说，是一个全方位的"刺激轰炸场"：头顶的广播、两边堆满的货架、冷柜的嗡嗡声、推车里来回晃、还不停有人从旁边过。他本来就要花更多力气去过滤这些，逛上十几分钟，那点"忍住"的力气就用光了。崩溃往往不是他当场"闹"，而是**他被刺激淹没之后，先关机了**。

所以最有效的处理，不在崩溃那一分钟，而在你进门之前。你提前给他一个**明确的任务**（照着清单找 3 样东西），他的注意力就有地方放，而不是被货架牵着走；你提前给他一个**撤退信号**，他不用在受不了的时候扯着嗓子喊"我要出去"，你也不用当众逼他"再忍忍"；你提前备好一个**降刺激动作**，嘈杂一上来，他有个东西能把自己拉回来一点。

这是外出场景里实践常用的预防做法，直接对照研究证据有限；背后的方向——用外部结构和提前约定减少临场冲突——见 [依据与出处](#依据与出处)。

## 具体怎么做

### 出门前的 3 个预防动作（按顺序做）

| 动作 | 怎么做才算做到 | 别做成什么样 |
|---|---|---|
| 1. 写"只买 3 样"清单 | 进门前列好，让孩子参与画 / 贴，告诉他"今天就找这 3 样" | 不列清单、想到啥拿啥，让他在货架间漫无目的地逛 |
| 2. 约定"人多就走"暗号 | 出发前说定一个动作（摸耳朵 / 拍两下肩），并告诉他"一做这个，我们就出去，不批评你" | 只口头说"人多就说啊"，没约定信号，他受不了时只会大哭 |
| 3. 备一个降刺激小物 | 固定放包里：耳罩、捏捏乐或熟悉的水，一到人多嘈杂处给他 | 每次临时找东西、或把手机当唯一的安抚物 |

### 到了超市，照着这几条走

- **把任务交给他：** "你来帮我找牛奶和鸡蛋，找到了放进车。"有活儿干的孩子，比被推着走的孩子稳。
- **暗号一响就执行，不带条件。** 你一摸耳朵，就推车出去门口站两分钟。做到一次，下次这个信号才灵；否则他以后不信。
- **人最多的区域（熟食区、排队结账）尽量快进快出**，别在冷柜前久站。
- **不逛"超预算"的店。** 周末晚高峰人挤人时，改到人少的时段或线上下单，不是认输，是选战场。

**做对了的标志：**
- ☐ 这次出门前，清单是和孩子一起列的
- ☐ 你们有一个固定暗号，并且一说 / 一做就真的执行
- ☐ 包里那个降刺激小物，是上次出门就放在那的
- ☐ 全程你没有说"你怎么又受不了了""别人都没事就你事多"

## 什么情况下需要换一种做法

- **做了这 3 个动作，还是每次出门都崩、连小区门口都待不住**：说明困难可能不止于"刺激太多"。下一步：[行为记录表](B05_行为记录表-记录什么不记录什么.md)，把每次崩溃的时间、地点、逛了多久记两周。
- **崩溃一发生你自己也压不住火**：先别纠结技巧，先把你自己的情绪安顿好。下一步：[家长自己崩溃之后：修复对话的脚本](B03_家长情绪崩溃后怎么办-修复对话脚本.md)。
- **一到人多的地方就崩溃，同时还有强烈的害怕、躲、拒绝出门**：这可能不只是注意力的问题，值得和专业人员聊。下一步：[就诊前要准备什么](../书籍A_公开知识库/A04_就诊前要准备什么.md)。

## 常见误区

| 误区 | 实际 |
|---|---|
| "崩溃了当场哄好就行" | 当场处理救急，出门前的预防才是治本 |
| "多带他出去练练，习惯就好了" | 没带工具的"练"，多半是反复崩；先把清单和暗号备上 |
| "暗号就是吓唬他，让他老实点" | 暗号是真的能撤退的信号，骗几次就废了 |
| "他就是想要零食才闹" | 很多崩溃是被刺激淹没，和要不要买东西是两回事 |

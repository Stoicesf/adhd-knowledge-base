# 目标行为的定义与数据追踪表模板

## 适用对象与使用前提

本页用于家长培训、学校行为支持与个案管理，把"不专心""脾气大"这类主观说法，换成可观察、可计数的行为定义，并在同一指标上做基线与干预对比。使用前提：先记录、后干预；不要一边改做法一边记数。

> **本手册不讨论药物选择与剂量。** 家长询问用药时，标准回应：这需要由开具处方的医生判断，我可以帮你整理要问医生的问题。

## 怎么把目标行为写成可计数的定义

一个合格定义要同时说清三件事：在什么情境下、做什么动作算 1 次、用什么单位数。常见替换如下：

| 不合格定义（主观、无法数） | 合格定义（可观察、可计数、带情境） |
|---|---|
| 孩子不专心 | 数学作业开始后 10 分钟内，双脚离开椅子的离座次数 |
| 脾气大 | 被纠正后 5 分钟内出现哭闹或摔笔的次数 |
| 写作业磨蹭 | 从被叫"开始写作业"到拿起笔之间的分钟数 |
| 不听指令 | 单次指令发出后 10 秒内照做的次数（一周累计服从率） |
| 上课爱说话 | 每节课未经举手主动插话的次数 |
| 太粗心 | 数学作业中漏看题目符号而算错的题数 |

定义里不要写"态度""注意力"这类内在状态；只写眼睛能看到、手能数到的动作。

## 用 ABC 记录法定位前因与后果

每行一条记录。A（前因）= 行为发生前刚刚发生了什么；B（行为）= 按上面定义数到的次数或时长；C（后果）= 行为出现后周围人怎么反应。连续记 3–5 天，前因重复出现的模式，就是下一步要调整的地方。

## 三种计数指标

- **频次**：一段时间内发生几次（如每节课离座 8 次）。适合发生离散、容易数的行为。
- **时长**：一次持续多久（如一次哭闹 12 分钟）。适合哭闹、走神这类持续状态。
- **延迟**：从"应该开始"到"真的开始"隔多久（如被叫后 25 分钟才坐到餐桌）。适合磨蹭、启动困难。

一个行为只选一个主指标。同时数三种，记录负担会压垮家长。

## 可直接使用的数据追踪表

| 日期 | 情境（如 晚 7:00 数学作业） | 指标类型 | 前因(A) | 计数/时长/延迟 | 后果(C) | 备注 |
|---|---|---|---|---|---|---|
| 例 11/05 | 晚 7:00 数学作业 | 频次 | 桌外放着平板 | 离座 6 次 | 每次家长口头提醒 | 提醒后约 2 分钟回座 |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

每天固定同一时段记，连续 5–7 天。一张表只记一个目标行为。

## 基线期与干预期怎么比较

先不做任何新干预，按同一指标连续记 3–7 天，取每天均值，这就是基线。之后引入环境或行为干预，再用同一张表记 3–7 天。比较只做简单均值对比：

- 例：基线日均离座 8 次，干预期日均 4 次，下降约 50%。
- 例：启动延迟基线平均 20 分钟，干预后平均 10 分钟，缩短约一半。

只看均值与百分比的方向和幅度，不在这一阶段做统计检验；样本只有几天，显著性没有意义。

## 常见误区

| 误区 | 实际 |
|---|---|
| 定义越细越好 | 家长记不动就会放弃；一个目标、一个指标、一张表，比三个目标更能坚持 |
| 记一天就能看出趋势 | 单日波动很大，至少 3–7 天才看得出基线水平 |
| 行为变好就不用记了 | 结束记录后容易回弹；维持期每周抽查 1–2 天更稳 |
| 分数降了全是干预的功劳 | 这里不做归因，只看指标变化；因果判断需要更严格的设计 |

> 本页提供的是行为记录与数据追踪方法，不构成诊断或治疗建议；诊断与医疗处置由具备资质的专科医生在评估后做出。

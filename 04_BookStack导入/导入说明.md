# BookStack 导入说明（ADHD 知识库内容包）

本目录下的脚本与文件用于把 `F:\ADHD文献\02_内容包\` 下的 Markdown 页面批量导入一个真实的 BookStack 实例。
**本轮不部署**：本目录不含 Dockerfile / docker-compose，也没有连任何 BookStack 实例。下面是运维照做即可的步骤。

## 1. 为什么不能直接"上传 zip 批量导入"

**BookStack 没有原生 Markdown 批量导入功能。** 它不支持 `.zip` 包整包导入，也没有"批量粘贴 Markdown"的后台入口。官方提供的导入路径只有：

1. **REST API v1 脚本批量创建**（本包主路径）——本目录 `import_bookstack.py`；
2. **后台手工新建页面 + 源码模式粘贴 Markdown**（兜底路径）——见 §3。

两条路径都在下面写清。

## 2. 主路径：API 脚本导入

### 2.1 在 BookStack 后台创建 API Token

1. 用**系统管理员**账号登录 BookStack。
2. 右上角头像 → **设置 (Settings)** → 左侧 **API**（或直接访问 `/settings/api`）。
3. 点 **新建 Token (Create Token)**：
   - **Token 名称**：`adhd-kb-importer`
   - **权限**：至少勾选 `create`、`update`、`view`，作用域覆盖 Book / Chapter / Page 三类。
   - 保存后**立刻复制** `Token ID` 与 `Token Secret`（Secret 只显示一次）。
4. 确认该后台账号本身对四个目标书籍有编辑权限（脚本会创建书籍，所以账号需要 `books-create` 权限；建议直接用管理员账号跑首次导入）。

### 2.2 传参方式（二选一）

**方式 A：环境变量（推荐，避免 Secret 出现在 shell 历史里）**

PowerShell：
```powershell
$env:BOOKSTACK_BASE_URL    = "https://kb.example.com"
$env:BOOKSTACK_TOKEN_ID    = "xxxxxxxxxxxxxxxx"
$env:BOOKSTACK_TOKEN_SECRET = "yyyyyyyyyyyyyyyy"
python F:\ADHD文献\04_BookStack导入\import_bookstack.py
```

**方式 B：命令行参数**
```powershell
python F:\ADHD文献\04_BookStack导入\import_bookstack.py `
  --base-url https://kb.example.com `
  --token-id xxxxxxxxxxxxxxxx `
  --token-secret yyyyyyyyyyyyyyyy
```

### 2.3 先 dry-run，再实跑

```powershell
# 第一步：完全离线校验 19 条内容页，不发任何请求
python F:\ADHD文献\04_BookStack导入\import_bookstack.py --dry-run

# 第二步：校验 18 条药品名壳页（--redirects-only 只导这 18 条）
python F:\ADHD文献\04_BookStack导入\import_bookstack.py --redirects-only --dry-run

# 第三步：确认退出码 0、无未解析链接后，再实跑
python F:\ADHD文献\04_BookStack导入\import_bookstack.py
python F:\ADHD文献\04_BookStack导入\import_bookstack.py --redirects-only
```

可选参数：
- `--only-book A|B|C|D`：只导入某一本书（分批改时用）。
- `--redirects-only`：只导入 18 条药品名壳页（见 §5）。

### 2.4 脚本做了什么

1. 读 `02_内容包\<书籍目录>\*.md`，解析 YAML frontmatter（面向/证据状态/最后审核/零用药勾选/页面类型/书籍/章节/slug）与正文。
2. 按规范 §1 建立三级结构：
   - 4 本书 slug：`public-kb` / `family-tools` / `clinician-handbook` / `clinical-boundary`
   - 章节顺序按 §1 表格硬编码。
3. `POST /api/books` → `POST /api/chapters` → `POST /api/pages`。
4. 页面正文以 `markdown` 字段提交。若实例的编辑器设置拒绝 markdown 字段（HTML-only 编辑器），脚本自动回退 `html` 字段并在日志里打印**"已回退"**。
5. **相对链接改写**：把 md 里的 `../书籍B_家庭工具与情景案例/B01_....md`、`A04_....md` 这类相对文件名链接，替换为 `<base>/books/<book_slug>/page/<page_slug>`。无法匹配的链接会在 dry-run 里列成"待人工处理"，不会静默丢弃。
6. **幂等**：按 slug 查找已存在的书籍/章节/页面，存在则 `PUT /api/pages/<id>` 更新，不重复创建。
7. 中文路径全程 `encoding="utf-8"`，读文件用 `utf-8-sig` 兜底 BOM。

## 3. 兜底路径：后台手工新建页面 + 源码模式粘贴

当 API 走不通（比如实例禁了 API、或 Token 权限谈不下来）时，用这条路：

1. 后台 → **书架 (Shelf)** → 新建 4 本书，名字与 slug 按下表：

   | 书名 | slug |
   |---|---|
   | 公开知识库（C 端） | `public-kb` |
   | 家庭工具与情景案例 | `family-tools` |
   | B 端工作手册 | `clinician-handbook` |
   | 临床边界参考 | `clinical-boundary` |

2. 在每本书里按 §1 章节顺序新建章节。
3. 进入每本书/章节 → **新建页面** → 右上角编辑器切到**源码模式 (Source mode)** → 把对应 `.md` 文件正文（去掉 YAML frontmatter 块）粘进去。
4. **slug 必须手工填**为 `导入结构清单.csv` 第 8 列的值（例如 A06 填 `medication-boundary`，A00 填 `start-here`）。
5. 相对链接手工替换：参考 `导入结构清单.csv`，把 `../书籍B_家庭工具与情景案例/B01_....md` 改成 `/books/family-tools/page/homework-leaving-seat` 这种站内 URL。
6. 每页粘完，在页面右侧"详情"里把"面向/证据状态/最后审核"补到正文顶部的元数据条里（md 文件已经写好，直接粘即可）。

这条路慢，但不依赖 API 权限；19 条内容页预计 1.5–2 小时，18 条壳页每条 30 秒（正文只一行 `#REDIRECT`）。

## 5. 药品名重定向壳页（`--redirects-only` 分支）

`F:\ADHD文献\03_零用药系统配置\重定向页保留清单.csv` 里裁决保留 **18 条**药品名壳页（商品名 9 + 分子名 5 + 其他通用名 4），它们对应的 `.md` 文件位于 `F:\ADHD文献\03_零用药系统配置\重定向页\`，正文仅一行 `#REDIRECT [兜底页链接] `（链接后带一个空格；无 YAML frontmatter）。

- 走同一套 API 脚本批量创建，加参数 `--redirects-only`：
  ```powershell
  python import_bookstack.py --redirects-only --dry-run    # 先看会建哪 18 条
  python import_bookstack.py --redirects-only              # 实跑
  ```
  它们会被建为 `public-kb` 书下的**顶层页面**（不挂任何章节），**不进任何导航目录**。
- **事实来源**：脚本以 `03_零用药系统配置\重定向页保留清单.csv` 为准，**不**扫目录里那 111 个 `.md`（其中 93 个已裁决下线，目录里暂时还躺着是另一分片的物理删除未做）。
- 权限（仅内容管理员可编辑）必须在后台手工设置，脚本不处理（见 §4 第 7 行）。
- 若 `--redirects-only` 分支因壳页格式未对齐而跑不通，兜底路径：在后台手工逐条新建页面，正文贴 `#REDIRECT [用药兜底页 URL] `（注意末尾空格），标题用关键词本身，slug 按保留清单第 5 列填。

## 6. 限制与已知问题

1. **API 不创建角色**，也不设置书籍可见性。角色/组/权限全部后台手工（见 §4 checklist）。
2. **不支持附件批量**：md 里引用的图片/附件需要手工上传到 BookStack 并替换链接。本批内容包正文不含图片。
3. **markdown 字段取决于实例编辑器设置**：若实例把编辑器锁成 HTML-only，脚本会自动回退 HTML 并在日志注明"已回退"；此时 Markdown 的表格/列表语法可能需要后台再修一遍。
4. **不创建书架 (Shelf)**：4 本书建完后，需要后台手工拖到一个书架里再挂到首页。
5. **壳页不进导航**：脚本只负责把页面建出来，"不进目录"靠后台权限与不挂章节实现（见 §4 第 7 行）。
6. **slug 以 md 文件 frontmatter 为准**：其他分片在 frontmatter 里写的 slug 与本目录 `_build_csv.py` 里的默认值若不一致，脚本以文件 frontmatter 为准，并在 dry-run 里报告。
7. **目录里仍有 111 个 .md**：另一分片尚未物理删除 93 个下线壳页；本包脚本以保留清单 CSV 为准，不会误导它们。等另一分片删完后，`REDIRECT_DIR` 里就只剩 18 个，与本包口径一致。

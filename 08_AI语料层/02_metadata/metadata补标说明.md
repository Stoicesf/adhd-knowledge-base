## 2. 字段填写规范（18 列）

| # | 字段 | 来源类 | 怎么填 |
|---|---|---|---|
| 1 | 编号 | 转录类 | 原样转录状态表"编号"列，不改写大小写与前缀（A01 / B30 / C01 / D01）。 |

| 4 | 面向 | 转录类 | 转录状态表"目标用户"列，按 schema 映射表归一到枚举；**单选**。双端写法（如"父母 / 教师"）取首位落入单选，次位写入第 17 列 `面向_次位`；"全部"映射为本枚举值 `全部`（面向所有读者，用于全库入口 / 边界声明页）。 |
| 5 | 页型 | 转录类（规则映射） | 状态表"页型"原值为渠道标签，仅作交叉校验；本层按正文标记与 §3.2 规则判定到五型枚举。渠道标签与判定矛盾时记入 §9，不回改正文。 |
| 6 | 证据状态 | 转录类 | 原样转录状态表"证据状态"列，不重新判定；取值域：强证据 / 有条件推荐 / 经验性策略 / 虚构教学案例 / —。 |
| 7 | 年龄段 | 抽取类 | 从正文实查抽取，依据正文学段表述与场景判定；多值用 `;`；跨两档及以上写 跨年龄；正文未给学段信息属信息缺失，写 `未标注`（**不等于跨年龄**）；抽不出写 待定 并登记 §11。 |
| 8 | 场景 | 抽取类 | 从正文实查抽取；多值用 `;`；九类均不贴合记 其他。 |
| 9 | 适用条件 | 抽取类 | 每条格式：`条件原文改写｜出处：文件名.md L<行号>「原句前 20 字」`；多条用 `;;` 分隔；每条必带正文出处；抽不出整条写 待定 并登记 §5。 |
| 10 | 不适用条件 | 抽取类 | 格式同上；记录"什么情况下本页做法不适用、需转介或换做法"；正文整节缺漏的登记 §6，单元格写 待定。 |
| 11 | 核心动作数 | 派生类 | 整数。计数口径：先数"今天能做的 N 件事"节顶层编号条目；该节缺失时数"具体怎么做"节顶层动作条目；只数顶层条目，不数表格行与子步骤。 |
| 12 | 含可照念话术 | 派生类 | 是 / 否。正文存在带引号、可整段复制给他人（老师 / 孩子 / 伴侣 / 医生）的固定话术块记 是；不论是否标注"照念"二字；无任何可复制台词记 否。 |
| 13 | 含反例 | 派生类 | 是 / 否。含误区对照表、反例对照、"不要这样说 / 不要这样做"式纠错条目记 是，否则记 否。 |
| 14 | 关联页 | 派生类 | 收集正文实质交叉链接（行内链接 + "下一条可操作建议"清单）目标编号，多值用 `;`；A00 首页导航链的链式罗列不计入。按 HR2（裁决一后口径）：每条关联边必有正文行号依据（见第 18 列 `关联依据`），无依据边不进主表；单向未登记转入 `待核验关联_106对.csv`，反补镜像边转入 `反补无据边_191条.csv`；本轮不要求 metadata 内双向对称。 |
| 15 | 高风险标记 | 高风险判定 | 单选，按 §3.5 优先级取最严；次要标签不丢，登记 §4 多属性页清单。 |

| 17 | 面向_次位 | 转录类 | 双端写法的次位读者；无双端读者记 `无`。 |
| 18 | 关联依据 | 派生类 | 与 `关联页` 逐条一一对应、顺序一致；格式 `目标编号=文件名.md L<行号>「锚文本前 15 字」`；每条关联边必带正文行号依据；无关联页记 `无`。 |

| 边界声明页 | 主要目的是说清这件事能做到什么、不能做到什么、下一步找谁；通常无填空表、无脚本。 | — |

## 0. 目的

把散落在 v1.6 规则、阶段四评测报告、部署后待办清单里的检索/生成规则，整合为一份**可执行配置**。输入 = 用户 query；输出 = 召回 chunk 列表 + 传给生成层的字段集合。所有规则落到具体字段名，不写空话。

## 1. 召回输入：query + metadata 四字段过滤

**metadata 四过滤字段**（取自 `01_schema/页面metadata_schema_v1.yaml` 第 5 条"metadata/chunk 行更新"，归属治理标准 v2 第 5 条；**非**页面头部四字段）：

| 字段 | 类型/枚举 | 检索层用法 |
|---|---|---|
| 面向 | enum: 本人/父母/伴侣/教师/B端/临床/全部 | query 含角色词（家长/父母/孩子/老师/本人/职场…）→ 命中对应值；`全部` 页始终参与（跨角色边界声明页） |
| 年龄段 | multi: 学前/学龄/青春期/成人/跨年龄/未标注 | query 含学段词（小学/初中/成年/职场…）→ 命中；`未标注` 页不参与年龄过滤（信息缺失，不假设） |
| 场景 | multi: 作业/早晨/睡前/学校/家庭冲突/社交/就诊/职场/其他 | query 含场景词 → 命中；多场景取并集 |
| 高风险标记 | enum: 安全事件/高敏感叙事/疗效暗示风险/无 | query 命中安全/敏感词 → 优先加权 安全事件 页（见 §7 路由） |

**过滤性质**：四字段为**软约束（排序加权）**，默认不硬性排除候选；唯 §4 角色护栏与 §7 安全路由可对特定页显式降权/提权。

## 2. chunk 召回规则（字段：可独立检索 / 双向召回 / 前置依赖）

**字段定义**（取自 `03_chunk/chunks_全量58页.csv` 表头，列序：证据状态=11、可独立检索=12、前置依赖=13、双向召回=14、双向判定依据=15、案例声明=18）：

- `可独立检索`（列12）：取值 `是` / `否`。=是 的块可单独进候选。
- `双向召回`（列14）：取值 `是` / `否` / `不适用`。=是 的块为"随父块带回"子块。
- `前置依赖`（列13）：`可独立检索=否` 块的父 块id；父块召回时子块随附。

**召回算法（顺序执行）**：

1. 命中 query 的 `可独立检索=是` 块 → 直接召回。
2. `可独立检索=否` 块 → **不单独召回**，仅当其 `前置依赖` 父块被召回时随父块带出。
3. `双向召回=是` 的块（不论自身 可独立检索 取值）→ 在其父块（`前置依赖` 或同页父子关系）被召回时一并带出。
4. **每父块最多带 2 个 `双向召回=是` 子块**（上限在**检索层**实现，不写死进 metadata）；超出 2 个时，按以下优先级取 top2：① `双向召回=是` 且 `可独立检索=否`（必须随父块带出的硬依赖）优先；② 其次按 `双向判定依据` 里是否含"免责句/边界声明/否定句"关键词（四类内容中优先级最高的两类）排序；③ 仍并列时按块 id 升序。

**B05 锚点（部署后待办·Q6）**：B05 阈值段落（"到什么程度带去看医生"）需确保 `可独立检索=是` 或被高相关父块 `双向召回` 带出。阶段四评测显示该段未进 top5（唯一真检索缺口），补 anchor 后真实向量复测。

## 3. 案例声明传递（字段：案例声明）

- **字段取值**（chunk 列18，与 metadata `证据状态` 对齐）：`无` / `虚构教学案例` / `经验性策略` / …。
- **规则**：`案例声明≠无` 的块被召回时，其 `案例声明` 字段值**随块一并传给生成层**；生成层据此决定呈现方式（见 §5）。
- `虚构教学案例` 块：生成层**不**作为"真实患者案例"呈现，仅作对话示范/示例，并显式标注"以下为教学示例"。

## 4. 角色护栏（字段：面向）

- **B44 具体定位**：编号 B44，`面向=本人`，成人本人情绪管理页；其家长版对应页为 **B32**（青春期孩子发脾气：家长先接情绪）。护栏规则：query `面向=父母` 时对 B44 降权，确保 B32 优先于 B44；query `面向=本人` 时对 B32 降权，确保 B44 优先于 B32。
- **反向对称**：query `面向=本人` 时，metadata `面向=父母` 页（如 **B32** 家长版）同样降权。
- **部署状态**：文档规则先定，实装在检索层/生成层。阶段四评测 Q4（B44 未召回）、Q29（召回未误用）表明当前词法检索未误用，但真实向量检索可能误召回，本护栏为防御性配置。

## 5. 证据状态过滤（字段：证据状态）

- **字段取值**（metadata `证据状态` / chunk 列11）：`强证据` / `有条件推荐` / `经验性策略` / `虚构教学案例` / `—`。
- **规则**：
  - `经验性策略` → 生成层回答强制附标注："【经验性策略，供参考不构成诊疗结论】"，不与 `强证据`/`有条件推荐` 混同。
  - `虚构教学案例` → 不进入正式事实回答，仅作示例，且标注"教学示例"（与 §3 联动）。
  - `强证据`/`有条件推荐` → 可正常作为依据，但生成层仍不得越出 A06 边界（§7）。
  - `—`（如 A00 首页）→ 仅作入口导航，不承载结论。

## 6. 零用药兜底（字段：编号 / 高风险标记 / query 药物关键词）

- **触发**：query 含药物关键词（药/用药/剂量/补剂/保健品/处方/副作用…）→ **强制优先召回 `编号=A06`**（slug `medication-boundary`，零用药边界声明页）。
- **规则**：
  1. A06 始终进 top 召回（即便 query 未显式命中 A06 文本），作为药物边界基线。
  2. 生成层输出**必须包含** A06 边界声明："不推荐具体药物/补剂；不替代正规评估与医嘱；警惕越线话术"。
  3. 与 `高风险标记=疗效暗示风险` 联动：命中该标记的页降权，避免疗效承诺外溢。
- **评测佐证**：Q22（"某补充剂能治"）原必命中 A06 属设定错，修正后必命中 **A09**（补充剂归 A09）；A06 仍为零用药总纲兜底，二者分工：A06=药物/零用药边界总纲，A09=补充剂专项。

## 7. 生成层约束（跨字段，硬规则）

1. **不越 A06 边界**：不得推荐具体药物/剂量/补剂，不得替代面诊与医嘱（与 §6 联动）。
2. **不抬高证据等级**：不得将 `经验性策略`（证据状态）说成 `指南推荐`/`强证据`（与 §5 联动）。
3. **安全事件必路由**：query 命中 `高风险标记=安全事件` 或含自伤/伤人/欺凌/失踪等词 → 优先召回并路由至 **B37**（安全事件页）与 **C03**（安全/危机页），生成层**首条**输出安全转介动作，不先给普通建议。
4. **角色适配**：按 §4 护栏，家长问法不优先给 `面向=本人` 内容。
5. **案例呈现**：按 §3/§5，`虚构教学案例` 仅作示例标注。
6. **引用可核验**：生成层引用须可回溯到 chunk `块id`/`行号起~行号止`，不可核验不输出为事实。

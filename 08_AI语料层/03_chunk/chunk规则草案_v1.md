## 1. 切分单元与层级

1. **一页一单元**：chunk 不跨页，不合并两页的短节。
2. 一级切点 = **H2**；一级块 = 一个 H2 及其下全部内容（含其内 H3、表、引用、清单）。
3. 二级切点（仅当一级块 >900 字）：优先按 **H3**；无 H3 时按 **顶层编号条目组 → 表格前后 → 引用块边界** 找边界。
4. **页首声明行 L12–L13**（`> 面向 / 证据状态 / 最后审核 / 零用药勾选`）与 H1 一并**并入首块**，不单独成块；首块行号自 **L12** 起。这 2 行每页 83 字，漏掉会造成页内字数缺口（试点已按 L12 起切，41 块字数合计与 5 页整页字数完全相等）。
5. **首块合并（v1.4 补，试点 A11 先例制度化）**：页首块若仅含「声明行 L12–L13 + H1 + 1–2 句导语」且字数 <150，与紧随的「今天能做的 N 件事 / 接下来可以做的 N 件事」**合并为 1 块**（合并后通常 218–296 字，落回目标区间）。这一条不影响「首块必须自 L12 起」的覆盖要求。
6. `## 今天能做的 N 件事` 与 `## 具体怎么做` 各自成块，不合并（检索命中的是动作，不是页）；仅当首块已按上条合并时，「今天能做的 N 件事」才随首块走。

## 3. 结构保护与三条硬约束

### 3.1 表格：不按字节切（约束一，裁决③分两类写清）

**禁止在表格内部落切点**：表头行、分隔行、数据行是一个整体，不得因 600/900 阈值把表头与表体分开。两类表格两种处理，全量切分不许混用：

| 类别 | 适用页 | 处理 | 是否算「主动独立成块」 |
|---|---|---|---|
| A 类：模板页填写表 | 页型=模板页（B04/B05/B14/B21/B24/B39/B40/C01） | **默认独立成块**，类型=表格，`可独立检索=是`，`前置依赖`=前置填写口径块 | 是，**主动独立** |
| B 类：非模板页表格 | 其余 55 页 | **默认跟所属节同块**，不主动独立；节 ≤900 整节一块 | 否 |
| C 类：任何页的表 >900 字 | 全部（实测触发 1 处：**A00 入口表 8 行 3,173 字**） | 按行拆，每子表重带表头行，标 `表格拆分=是`，子表 `前置依赖` **星形**指首子表（不用环形互指：环会破坏悬空与环路校验） | 否，**超长被动拆分**，不属主动独立 |

要点：B 类是「表随节走」，C 类是「表太长被迫拆」，两者都不是 A 类的「主动独立成块」；只有页型=模板页才走 A 类。全量切分按页型字段判 A/B，按字数判是否触发 C。

**C 类拆法细则（批次 1 落地，v1.4 补）**：
1. 触发条件是**字数**不是行数。v1.3 曾写“本项目最长 10 行，不触发”，**该判断有误**，已由 A00 入口表（8 行 3,173 字）证实。
2. 每子表 = 原表头行 + 分隔行 + 1 行数据（或按行数让每块 ≤900）。**表头重复注入**，故 `字节数`/`字数` 含注入量，页内字数校验须**扣除注入量**后再与整页字数比对（A00 注入 5×34=170 字）。
3. 子表 `前置依赖` 星形指首子表，环状互指不用。
4. 子表 `可独立检索=是`（每行自带“情况→适合谁→先看什么”，脱离表头也可读）。

### 3.2 强依赖段：不强制切（约束二）

1. 定义：动作与其退路 / 不适用条件 / 转介条件同属一个语义单元；话术与其触发条件；判据与结论。切开后单块会被误读。
2. **600–900 字：不切**。实例：B37-c04（858 字，三段照念脚本 + 触发条件 + 红旗）按此保留。
3. **>900 字：必须切**，切开后主块 `可独立检索=是`，从属块 `可独立检索=否` 且 `前置依赖` 指主块，召回时成组返回。实例：B08「依据与出处」2,195 字 → 4 段 710 / 483 / 859 / 143。

**依据段的可独立检索判定（裁决②）**：切开后的依据段逐块判，不按「依据一律否」一刀切。

- 该段是连续论述、脱离上下文仍能独立成立（自带条目名、自带结论）→ 标 **是**。
- 该段含**程序性回指**——「见上文第 X 条」「页内原句」「如上」「本页据此」等，指向必须逐字读取的具体文本、不读就无法定位所指 → 标 **否**，`前置依赖` 指其父块。
- 该段仅含**概念性回指**——「上述结构判断」「这类做法」等指向可常识补足的概念，句子去掉指代对象仍自成语义 → **可维持 `是`**（试点实例：`D01-c03` 的「不替代上述结构判断」）。
- **概念性回指的判定标准（v1.4 补）**：回指对象是「读者凭常识可补足的概念」才算概念性；若回指对象是「必须逐字读前文才能理解的程序步骤」（如「按第 3 条执行」「见上文第 X 项」），一律按程序性处理、判 `否`。
- **序位回指 = 程序性（v1.5，裁决一，已定不再待定）**：**两类命中即判 `否`**——
  - **(a) 同一场景、同一时点的连续脚本**里的「第 N 步」块：前序步承载框架或前置判断（如「分 3 步」写在第一步、第 1 步是安全判断），单独召回第 2 步会让生成层跳过第 1 步直接输出话术 → `否` + `前置依赖` 指脚本框架块（`c04a`）+ `双向召回=否`；
  - **(b) 块内含跨块序位指涉**（「按第 3 步处理」「见第 N 条」等），必须回查才知所指 → `否` + 依赖被指块。
  - **不判否的情形（须逐条登记理由）**：序位只作标题序号，各步是**不同时点、可分别落地的独立动作**（如 B33 的「开账户 / 定额度 / 大额暂停 / 固定对账 / 记账收口」五件财务安排，每段自带完整判据），且无跨步指涉 → 可维持 `是`。这不是「每步自带动作所以可独立」的写作者视角，而是脚本连贯性与动作清单的结构区别；判断依据写进回指清单。
  - **落地实例**：`B22-c04b/c04c`、`B26-c04b/c04c`（连续三步修复对话）→ 否 + 依赖各自 `c04a` + `双向召回=否`；`B33-c03a…c03f`（五件独立安排）→ 是，仅 `c03b` 的「按第 3 步处理」记软依赖 `c03c`。
  - 已执行的待定块**无需改字段值**时（原按「暂按否」填），只改 `备注` 的“回指类型待定”表述与 `双向判定依据`，并在校验记录记账；**不得为对齐口头计数而改其他块判定**。
- **边界案例不自行裁定**：除上述序位回指外，既像概念性又像程序性的，逐条记录、标 `回指类型待定`（`回指类型` 字段值），`可独立检索` 暂按「否 + 依赖父块」填，**提交时单列《回指类型待定清单》**交裁决方裁定，切分方不得自行拍板。
- 判定理由必须写进校验记录，不许只填字段。

### 3.3 依赖标注必须成立（约束三）

1. `可独立检索=否` ⇒ `前置依赖` **必填**，值为同页父 `chunk_id`。
2. 父块必须 `可独立检索=是`；依赖只指**同页、前序**块，不跨页、不跨书。
3. **无父的「否」= 错误标注**；悬空依赖 = **0** 是试点验收硬指标，逐条核，不在切完后补标。
4. `是` 块也可有软依赖（如模板表依赖填写口径），软依赖不改变可独立判定。
5. **双向召回（v1.3，裁决一）**：仅对 `可独立检索=否` 的块判，**按块的内容性质、不按页型一刀切**。
   - 内容属以下四类之一 → `双向召回=是`：**否定句 / 边界声明 / 免责句 / 转介触发条件**；
   - 其余 → `双向召回=否`（如依据清单、页尾导航、证据台账式判定说明）；
   - `可独立检索=是` 的块 → `双向召回=不适用`。
   - 语义：`是` 表示**父块被召回时必须一并带出该子块**，否则父块信息会残缺（试点实例：`B37-c04` 三段照念脚本必须带上 `B37-c01` 的虚构标注；`D01-c02` 结构摘要必须带上 `D01-c01` 的「不构成诊断依据」）。
   - 「否」块被召回时仍按其 `前置依赖` 带父块，方向不变。
6. **双向召回的数量上限不在 metadata 层做**（裁决三）：切分只标注、不限制；上限（建议单父块最多带 2 个 `双向召回=是` 子块）在检索层实施，避免切分阶段为凑上限改边界。
7. **逆向依赖（v1.6，裁决三，仅限虚构声明块）**：`前置依赖` 默认只指同页**前序**块。唯一例外是案例页的页首虚构声明块——**B37-c01 为逆向依赖，声明块在前、内容块在后，语义方向为声明约束内容，非内容依赖声明；此类逆向依赖仅限虚构声明块，其他块仍按前向依赖处理。**理由：声明块的功能是给主脚本块提供使用边界，不是被主脚本块支撑；若反向让主脚本块依赖声明块，声明块会变成父块，但声明块只有元信息、没有实质内容，不适合做父块。留痕方式：块 `备注` 写明逆向依赖与理由，校验记录单列一条，不因此改切点。

### 3.4 话术块

引号内「照念 / 照着说」的整段台词与其所属动作条目绑定；整块 >900 字时允许话术单独成块，块首补 `【照念话术·动作N】`。

### 3.5 红旗 / 转介段

`高风险标记=安全事件` 的 7 页：转介句必须与其触发条件同块，不许只把转介句切走。

### 3.6 顶层编号条目组

`1..N` 条目不跨块；一组超 900 字时按条目边界切，块首写 `（第 k–m 条 / 共 N 条）`。

### 3.7 类型豁免（不受 80 字下限）

「依据与出处」「页尾关联清单」两类块不受 80 字下限约束——它们本就短（实测 36–156 字），并入正文会污染召回。正文、表格、边界约束块仍受下限；边界声明页例外见 §5.2。

### 3.8 案例页虚构声明：走 metadata + 检索层，不进正文（v1.5，裁决二）

**不复制进各段**：案例页的“本页是虚构教学案例、不作证据”整句**不复制进每个 chunk 正文**——复制会让每块多 50–80 字噪声，且改的是正文，违反“不改正文”红线。

**改为三层机制**：

1. **`案例声明` 字段（chunk metadata 第 18 列）**：案例页所有块填 `本页为虚构教学案例，不作证据`；非案例页填 `无`。判定看**正文是否含虚构声明句**，不看页型字段（实例：B03 页型=案例页但正文无虚构标注，填 `无` 并在记录中留待裁）。
2. **检索层必须传递**：案例页块被召回时，须把 `案例声明` 字段**一并传给生成层**。只写进 metadata 而不传，等于没写——生成层看到的仍是一段像真实案例的文本。
3. **阶段四评测验证**：评测集须包含“引用案例页块作答”的用例，检查输出是否带出“虚构、不作证据”。**未被消费 → 在检索层补，不回头改正文、不改切分边界。**

**c04a 的双向召回条件**：若案例页的 `c04a`（步骤框架块）**本身含**整句虚构声明，则其 `双向召回` 判 `是`（免责句属四类内容）；若只含“场景（教学虚构）：”这类短标注、不含整句，则条件不触发，`c04a` 为「是」块、`双向召回=不适用`，声明由 `案例声明` 字段兜底。两条腿走路，不依赖单一机制。

**与证据状态的关系**：`证据状态` 照 metadata 现值（B22/B26=虚构教学案例，B37=经验性策略 + 备注待第 18 条修正），`案例声明` 是**独立字段**，不替代也不改写 `证据状态`。

## 4. 标题前缀与 metadata 继承

1. 每块首行注入标题链：`页题 > H2 > H3`（无 H3 则两级）；前缀计入存储，**不计入 §2 阈值判定**。
2. 每块继承 `metadata_63页.csv`：编号、页题、所属书、面向、页型、证据状态、年龄段、场景、高风险标记、最后审核。
3. 每块派生：`chunk_id`、页内序号、行号区间、字数、含表格、含话术、含红旗、类型、可独立检索、前置依赖。
4. **证据状态取值（裁决⑤）**：chunk 的 `证据状态` 一律取 `metadata_63页.csv` 当前值，与上层保持一致。B37 取「经验性策略」，并在该页全部 chunk 的 `备注` 列写：
   `证据状态待差异清单第18条修正后可能改为"虚构教学案例"，届时同步更新chunk metadata`
   第 18 条修正落地后，**只改 `证据状态` 这一字段，不动切分边界**。
5. 其他「已知待修」字段同理：先取上层现值 + `备注` 标注待修，不因待修而阻塞切分。
6. **`案例声明`（v1.5，第 18 列）**：`metadata_63页.csv` 无此列，不继承；由切分阶段按**正文是否含虚构声明句**判定填入（案例页含整句 → `本页为虚构教学案例，不作证据`；其余 → `无`）。口径与检索层要求见 §3.8。

## 5. 特殊情况预判（切之前定，切时验证）

### 5.1 B05 模板页（行为记录表）

- 结构：`## 具体怎么做`（L31–L57）实为三段——记什么/不记什么（L33–L41，192 字）、可打印记录表（L43–L51，215 字，7 行：表头 + 分隔 + 1 例行 + 4 空白行）、带去给谁看（L53–L56，172 字）。
- 预判：**表格独立成块**（B05-c04，215 字，可独立检索=是，前置依赖=B05-c03 填写口径）。「例：11/5 周二」那一行是填写示范，**必须留在表内**，删行模板就失效。

### 5.2 D01 边界声明页（诊断标准摘要）

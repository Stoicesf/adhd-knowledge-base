# 阶段四 评测报告（模拟检索）

> **重要方法声明（与阶段三方法局限一致）**：本评测为 **模拟检索下的近似结果**，不是真实 BookStack 检索。
> - **检索层**：以 Python 实现的轻量词法/字二元 IDF 检索器（BM25 思路），索引 63 页源正文 + metadata 边界摘要；**检索器对期望页盲**（不喂必须/应该命中页，避免作弊）。
> - **生成层**：由 LLM（本代理）按"召回的 top5 页 + 期望页"模拟 RAG 作答并评分，模拟回答仅作评分证据，非真实用户可见输出。
> - **top5 取法**：每题对 63 页打分取前 5 页；`是否命中期望页` = 必须命中页是否落在 top5。
> - **结论性质**：近似结果。真实检索行为（向量召回、真实 RAG 生成）待部署后补测；词法检索器对"同义改写不匹配"的页面可能低估召回，原 3 处未命中中仅 Q6 为检索器可能低估的真缺口（另 2 处 Q11/Q22 经复核为评测集设定错，见"评测集修正说明"），需真实向量检索复核。

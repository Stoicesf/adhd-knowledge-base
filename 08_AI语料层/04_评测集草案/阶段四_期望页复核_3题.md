# 阶段四_期望页复核_3题

> 目的：评测后结果解读。评测结果 CSV 与报告本身已接受，本文件只复核"3 处未命中"的**期望页设定是否合理**，不重跑评测、不改 chunk、不改报告。
> 复核方法：每题回答三问——① 必须命中页是否合理（该页正文是否直接回答这题）？② 应该命中页是否合理（更贴题的页是否被设成"应该"、更泛的页被设成"必须"）？③ 问法是否指向该页（问法关键词在该页正文有无对应表述）？
> 结论只有三种：**维持** / **改必须命中页** / **改问法**。

## Q6：青春期孩子暴怒——"到什么程度该带去看医生"

- **问题原文**：青春期孩子一发脾气就摔东西、连续几天不理人，我都在本子上记着，这到什么程度该带去看医生？
- **当前设定**：必须命中 **B05**，应该命中 **A04**
- **用户角色**：家长（青春期）

### 三问

**① 必须命中 B05 是否合理？**
合理。B05 虽是"行为记录表"工具页，但正文**直接含阈值/转介段落**：
- **B05 L61**：「记录显示困难跨场景、频率高，已经影响到学习和同伴关系：可以带着这张表去就诊了。下一步：A04」——这就是"到什么程度该带去看医生"的直接答点。
- **B05 L54**：「带去给医生/心理科专业人员。让他看到：困难出现在哪几个场景、每周几天、哪些调整有用。看的是'跨场景的一致性'。」
所以用户原假设"B05 只回答怎么记、不回答阈值"**不成立**——B05 既有"怎么记"也有"记到什么程度该去就诊"。

**② 应该命中 A04 是否合理？**
合理。A04 是"就诊前要准备什么"（材料清单+问题清单），且 **A04 L51** 给出更重的升级阈值：「孩子出现自伤念头、或情绪问题严重影响日常：不要等普通排期，尽快挂儿童精神科或心理科咨询」。Q6 问法里的"连续几天不理人"正好可对应"情绪问题严重影响日常"这一加急路由。A04 作"应该命中"（辅答+升级路由）恰当。

**③ 问法是否指向 B05？**
指向。问法含"我都在本子上记着"（对应 B05 记录表）、"这到什么程度该带去看医生"（对应 B05 L61 阈值）。关键词在 B05 正文均有对应表述。

### 结论：**维持**
必须命中 B05、应该命中 A04 的设定合理。评测中 B05 未进 top5，**这是真检索缺口（设定没错、召回失败）**，不是设定问题——与 Q11/Q22 性质不同，应走"部署后真实向量补测 + B05 chunk 锚点"路径（见裁决四待办），**不改评测集、不改 chunk 现阶段**。

## Q11：成人门诊看成人 ADHD，提前准备什么材料

- **问题原文**：我成年了想去门诊看成人ADHD，要提前准备什么材料？
- **当前设定**：必须命中 **A04**，应该命中 **A07**
- **用户角色**：成人本人

### 三问

**① 必须命中 A04 是否合理？**
**不合理**。A04 正文定位是**儿童/家长视角**：
- **A04 L2**：`面向: 父母`
- **A04 L25**：「儿童 ADHD 的评估，核心是收集多场景证据……同时拿到家长、学校等不同来源的报告」
- 全页围绕"孩子""家长""老师反馈"，**无成人自诉、无成人跨场景时间线**。对"成人问准备什么材料"，A04 是**受众错配页**。

**② 应该命中 A07 是否合理（被设成"应该"的页是否更贴题）？**
A07 才是正解页，应设为"必须"：
- **A07 L2**：`面向: 本人`
- **A07 L15**：「成年后第一次想评估自己：先整理哪些材料」
- **A07 L33-41**：直接给出成人材料清单（跨场景时间线 / 他人反馈 / 成长史一页纸 / 现状随手记 / 问题清单）——**逐字回答"准备什么材料"**。
- **A07 L58**：「准备完材料不知道挂什么号：参考 A04 的就诊路径说明」——A04 在此被 A07 当作"路径参考"，而非"材料页"。

结论：**必须/应该 主次颠倒**。A07（成人专用）比 A04（儿童通用）更贴题，应 必须=A07、应该=A04（降级为路径参考或移除）。

**③ 问法是否指向 A07？**
强指向。问法"我成年了""看成人 ADHD""准备什么材料"对应 A07 L15/L33 的"成年后第一次想评估自己""整理哪些材料"。A04 的"孩子/家长"关键词在问法里**完全不出现**。

### 结论：**改必须命中页**
必须命中 **A04 → 改为 A07**；A04 降为"应该命中（路径参考）"或移除（其儿童/家长受众与成人问法错配）。
**性质：评测集设计错误，非检索系统问题**——评测中 A07 已在 top5、A04 未进，恰是"成人专用页比通用页更贴题"的正常召回，原"Q11 缺 A04"是错把儿童页当必须的误报。

## Q22：群里说某补充剂能治 ADHD，能信吗

- **问题原文**：群里有人说某补充剂能治ADHD，能信吗？
- **当前设定**：必须命中 **A06**，应该命中 **A09**
- **用户角色**：家长（学龄）
- **附加裁定**：补充剂归 A06（药物兜底）还是 A09（非药物训练边界）？

### 三问

**① 必须命中 A06 是否合理？**
**不合理**。A06 是"关于药物：本库能回答什么、不能回答什么"，其边界**只覆盖处方药物决策**：
- **A06 L41-46「本库不能回答什么」表**：是否该用药 / 用哪一种用多少 / 出现不适怎么办 / 何时停或减——**四项全是"药"，无"补充剂/保健品/补剂"一字**。
- A06 定位 slug `medication-boundary`（处方药边界），不承载补充剂内容。

**② 应该命中 A09 是否合理（被设成"应该"的页是否更贴题）？**
A09 才是补充剂的正解页，应设为"必须"：
- **A09 L42**（话术表）：「调理饮食 / **补 XX 营养素** / 戒色素添加剂，就能治好多动症。」——直接把"补营养素能治"列为踩线话术。
- **A09 L85**（NICE 依据）：「不要建议或提供膳食**脂肪酸补剂**用于治疗儿童与青少年 ADHD。」——明文补剂边界。
- **A09 L61**：「机构的人开始和你聊'要不要配合吃药'……本库不涉及药物相关问题，边界与可回答范围见 A06」——**A09 在此明确把"药"问题让渡给 A06，自身只管"非药物训练/补剂/营养素"类越线话术**。

→ **裁定：补充剂归 A09，不归 A06。** A09 含 L42/L85 的补充剂表述，A06 无。

**③ 问法是否指向 A09？**
强指向。问法"补充剂能治"对应 A09 L42「补 XX 营养素……就能治好多动症」的踩线话术模板，及 L85 的补剂禁忌依据。A06 的"药/用药决策"关键词在问法里不出现（问的是"补充剂"非"药"）。

### 结论：**改必须命中页** + **补充剂边界裁定**
必须命中 **A06 → 改为 A09**；A06 降为"应该命中（药物决策总纲/参考）"或移除。
- **A06 不记正文缺口**：其定位即处方药物决策边界，库内"补充剂/保健品"内容由 A09 承载，A06 无需补写补充剂表述。
- **原"Q22 真缺口"结论撤销**：评测中 A09（含补剂边界）已在 top5，A06 未进是因其本就不含补充剂内容；这不是检索失败，是错把药物页当必须的误报。
- 性质：**评测集设计错误，非检索系统问题**。

## A06 / A09 补充剂表述核查（原文贴出）

### A06：无补充剂/保健品/补剂表述
A06 全文仅覆盖处方药物决策。其"本库不能回答什么"表（**L41-46**）原文：

| 本库不能回答什么 | 为什么 |
|---|---|
| 是否该用药 | 必须由医生评估后决定，本库不提供 |
| 用哪一种、用多少 | 同上，本库不讨论 |
| 出现不适怎么办 | 同上，本库不展开 |
| 何时停或减 | 同上，本库不展开 |

→ 四项均围绕"**药**"，**无"补充剂/保健品/补剂/营养素"任何表述**。

### A09：有补充剂/保健品/补剂表述（3 处）
- **L42**（话术表·踩线话术）：「调理饮食 / **补 XX 营养素** / 戒色素添加剂，就能治好多动症。」——对应"指南不建议把人工色素添加剂剔除或脂肪酸补剂作为普遍治疗"。
- **L85**（NICE §1.6.4 依据）：「不要建议或提供膳食**脂肪酸补剂**用于治疗儿童与青少年 ADHD。」
- **L61**（换做法）：「机构的人开始和你聊'要不要配合吃药'或者'别吃医院开的药，吃我们的调理'：本库不涉及药物相关问题，边界与可回答范围见 A06」——A09 把"药"让渡 A06，自身管"补剂/营养素/调理"类非药物越线话术。

→ 库内"补充剂/保健品"边界由 **A09** 承载，裁定补充剂**归 A09**。

# 角色与权限配置表（BookStack 后台照做版）

> 本文件只写"在后台勾什么、在哪一层设、设完怎么验证"，不重复概念说明。
> 适用实例：本知识库 4 本书（A `public-kb` 公开知识库 / B `family-tools` 家庭工具与情景案例 / C `clinician-handbook` B 端工作手册 / D `clinical-boundary` 临床边界参考）。
> 通用约定：凡 BookStack 菜单名随版本可能不同处，均标注"**以你所装版本后台为准**"；拿不准时先在后台设置页搜索功能名称，不要凭本文件字面硬找。
> 配套阅读：`发布流程与信任分级SOP.md`（流程例外规则与本表配套使用）。

---

## 1. 角色总览：默认角色与自定义角色

BookStack 自带的系统角色只有两个，本库不把它们当内容角色用：

| 角色 | 性质 | 本库用途 |
|---|---|---|
| **Guest（访客，未登录）** | 系统默认 | 对全部 4 本书均**不可见**（见 §3 矩阵的 Guest 说明）。 |
| **Admin（系统管理员）** | 系统默认 | 仅技术运维备份账号（管设置、用户、API 令牌），**不承担内容编辑职责**；内容侧的最高角色是下方"内容管理员"。 |

其余 5 个内容角色**全部为自定义角色**，需要手工新建：

**新建自定义角色的后台路径**：登录 Admin 账号 → **Settings（系统设置）→ Roles（角色）→ Create New Role / 新建角色**（菜单名以你所装版本后台为准）。

新建时逐字段填写：

| 字段 | 填法 |
|---|---|
| Display Name（显示名） | 中文角色名，例如"内容管理员" |
| Description（描述） | 一句话写清职责，例如"C 端内容定稿与兜底页维护" |
| System Permissions（系统权限组） | 见 §2 各角色清单；**5 个内容角色一律不勾**用户管理/角色管理/系统设置（那些归 Admin 账号） |
| Entity Permissions（实体权限组） | 按 Books / Chapters / Pages 三行分别勾 创建 / 更新 / 更新全部 / 删除 / 删除全部（具体勾选项名称以你所装版本后台为准） |

> 说明：BookStack 的"更新"与"更新全部"是两个勾选项——**"更新"只能改自己创建的内容，"更新全部"才能改别人创建的内容**。本库大量权限设计依赖这个区分，见 §2、§4。

## 2. 五个角色的逐项勾选清单

勾选符号：✅ = 勾选；⬜ = 不勾。下表按角色逐行列出**角色层（Settings → Roles → 编辑该角色）**的勾法。

### 2.1 读者（自定义角色：登录后的普通访问者）

| 权限组 | 权限项 | 勾选 |
|---|---|---|
| Books | 查看书籍 | ✅ |
| Books | 创建 / 更新 / 更新全部 / 删除 / 删除全部 | ⬜（全不勾） |
| Chapters | 查看章节 | ✅ |
| Chapters | 创建 / 更新 / 删除 | ⬜ |
| Pages | 查看页面 | ✅ |
| Pages | 创建 / 更新 / 更新全部 / 删除 / 删除全部 | ⬜ |
| 评论 | 创建评论 | ✅（允许对页面提问/反馈，反馈由内容管理员每周汇总） |
| 评论 | 编辑/删除他人评论 | ⬜ |
| 附件 | 查看附件 | ✅ |
| 附件 | 上传 / 删除附件 | ⬜ |
| 导出 | 允许导出单页（PDF / HTML / 纯文本） | ✅（B05 行为记录表等需家长打印） |

### 2.2 C 端贡献者（自定义角色：家长/志愿者供稿）

| 权限组 | 权限项 | 勾选 |
|---|---|---|
| Books | 查看 | ✅；创建/更新/删除 ⬜ |
| Chapters | 查看 | ✅；创建/更新/删除 ⬜ |
| Pages | 查看 | ✅ |
| Pages | 创建 | ✅（只能在书籍 A/B 实际可写——由 §3 书籍级权限收口） |
| Pages | 更新 | ✅（**只能更新自己创建的页面**） |
| Pages | 更新全部（改别人的页） | ⬜（硬要求：见 §4 页面级清单） |
| Pages | 删除 / 删除全部 | ⬜（任何页面不得自行删除，留痕优先） |
| 评论 | 创建评论 | ✅；删改他人评论 ⬜ |
| 附件 | 查看 + 上传（限自己创建的页面） | ✅；删除附件 ⬜ |
| 导出 | 允许导出 | ✅ |

### 2.3 B 端编辑（自定义角色：专业服务人员写工作手册）

| 权限组 | 权限项 | 勾选 |
|---|---|---|
| Books | 查看 | ✅；创建/更新/删除 ⬜（书目结构由内容管理员定） |
| Chapters | 查看 | ✅；创建/更新/删除 ⬜ |
| Pages | 查看 | ✅ |
| Pages | 创建 | ✅（生产场所在书籍 C，由书籍级权限收口） |
| Pages | 更新 + 更新全部 | ✅（可修订他人稿件；但在书籍 A 的修改按 SOP 须经 C 端组长复核） |
| Pages | 删除 / 删除全部 | ⬜（错版走退回改写单，不直接删） |
| 评论 | 创建评论 | ✅；删改他人评论 ⬜ |
| 附件 | 查看 + 上传 | ✅；删除附件 ⬜ |
| 导出 | 允许导出 | ⬜（书籍 C 为内部手册，不开放对外导出；单页导出开关若在系统级统一开启，则在书籍 C 的书籍级权限里另行关闭——以你所装版本后台为准） |

### 2.4 临床审核（自定义角色：医学边界把关人）

| 权限组 | 权限项 | 勾选 |
|---|---|---|
| Books | 查看 | ✅；创建/更新/删除 ⬜ |
| Chapters | 查看 | ✅；创建/更新/删除 ⬜ |
| Pages | 查看 | ✅ |
| Pages | 创建 | ✅（书籍 D 由其维护） |
| Pages | 更新 + 更新全部 | ✅（审校 A/B/C/D 各页的医学表述） |
| Pages | 删除 / 删除全部 | ⬜ |
| 评论 | 创建评论 | ✅；可删除违规评论（按你所装版本是否有"删评论"勾选项决定，没有则由内容管理员代删） |
| 附件 | 查看 + 上传 | ✅；删除附件 ⬜ |
| 导出 | A/B 书允许导出；C/D 书不导出（靠书籍级权限收口） | ⚠️ 角色层只开查看，导出随书籍权限 |

### 2.5 内容管理员（自定义角色：全库内容最终责任人）

| 权限组 | 权限项 | 勾选 |
|---|---|---|
| Books | 查看 / 创建 / 更新 / 删除 | ✅ 全勾 |
| Chapters | 查看 / 创建 / 更新 / 删除 | ✅ 全勾 |
| Pages | 查看 / 创建 / 更新 / 更新全部 / 删除 / 删除全部 | ✅ 全勾 |
| 评论 | 全部（创建/编辑/删除） | ✅ |
| 附件 | 全部（上传/查看/删除） | ✅ |
| 导出 | 允许 | ✅ |
| 系统权限 | 管理用户 / 管理角色 / 系统设置 / API 令牌 | ⬜（**归 Admin 账号**；内容管理员只管内容，不碰技术后台） |

## 3. 书籍级权限矩阵（4 本书 × 5 角色 = 20 格，逐格取值）

### 3.1 怎么开书籍级权限

入口：进入某本书 → 右上角 **Permissions（权限）** 标签页 → 打开 **Enable Custom Permissions（启用自定义权限）**（菜单名以你所装版本后台为准）。开启后：

- **"Everyone Else / 其他所有人"一行必须先关闭（不勾任何动作）**，再按需逐角色添加行——书籍 C、D 尤其照此办理，防止未登录游客和默认角色透过继承看到内容。
- 每格取值含义：✅允许 / ⬜禁止，每格后附一句依据。

### 3.2 矩阵

| 书籍 ＼ 角色 | 读者 | C 端贡献者 | B 端编辑 | 临床审核 | 内容管理员 |
|---|---|---|---|---|---|
| **A 公开知识库** `public-kb` | 查看✅／创建⬜／更新⬜／删除⬜。依据：公开层对登录读者开放阅读，但不开放生产。 | 查看✅／创建✅／更新✅（限自有页）／删除⬜。依据：C 端供稿经"待发布"流程入库，删除须留痕。 | 查看✅／创建⬜／更新✅／删除⬜。依据：B 端编辑可校订专业表述，但其对 A 书的修改按 SOP 须经 C 端组长复核；不开放新建以免双轨口径。 | 查看✅／创建⬜／更新✅／删除⬜。依据：负责 A 页（含 A06 兜底页）的医学边界把关，不直接写科普。 | 查看✅／创建✅／更新✅／删除✅。依据：全库内容定稿人。 |
| **B 家庭工具与情景案例** `family-tools` | 查看✅／创建⬜／更新⬜／删除⬜。依据：工具与案例页公开可读，生产权不开放。 | 查看✅／创建⬜／更新✅（限自有提交）／删除⬜。依据：B 书案例叙事页仅内容管理员可创建（见 §4），贡献者只能修订已有页。 | 查看✅／创建⬜／更新⬜／删除⬜。依据：B 端编辑的主场在 C 书，避免两套案例口径。 | 查看✅／创建⬜／更新✅／删除⬜。依据：审校案例中的医学表述边界。 | 查看✅／创建✅／更新✅／删除✅。依据：案例页生产权与定稿权归其所有。 |
| **C B 端工作手册** `clinician-handbook` | 查看⬜（全部禁止）。依据：B 端手册不向公众开放；**开启自定义权限后必须关闭"Everyone Else"继承，只添加 B 端编辑与内容管理员两行**。 | 查看⬜（全部禁止）。依据：C 书面向专业人员，C 端贡献者无阅读权。 | 查看✅／创建✅／更新✅／删除⬜。依据：C 书是 B 端编辑工作主场；错版走退回改写单，不直接删除以留痕。 | 查看✅／创建⬜／更新✅／删除⬜。依据：审 C03 转介话术等边界页，不代写操作模板。 | 查看✅／创建✅／更新✅／删除✅。依据：B 端手册最终责任人。 |
| **D 临床边界参考** `clinical-boundary` | 查看⬜（全部禁止）。依据：诊断标准摘要不得对 C 端开放，防止读者自行对号入座。**同样关闭"Everyone Else"继承**。 | 查看⬜（全部禁止）。依据：同上行。 | 查看⬜（全部禁止，含查看）。依据：D 书按设计只对临床审核与内容管理员可见，B 端编辑不开放阅读。 | 查看✅／创建✅／更新✅／删除⬜。依据：D 书即临床审核组的维护对象。 | 查看✅／创建✅／更新✅／删除✅。依据：内部兜底责任人。 |

### 3.3 Guest（未登录访客）补充行（不占 20 格，但必须执行）

- 书籍 A、B：**对 Guest 完全关闭**——在书籍 A、B 的自定义权限里，"Everyone Else"行查看权不勾（即 §3.2 读者行只在登录后生效）。验证：退出登录后直接访问 `https://<站点>/books/public-kb` 应跳转登录页。
- 书籍 C、D：本来就只添加了指定角色行，Guest 自然不可见；改权限后仍要按此复查一次。

## 4. 页面级覆盖清单（逐条写清：在哪一层设 + 设完怎么验）

### 4.1 A06 用药兜底页（slug `medication-boundary`）

- **要求**：仅内容管理员 + 临床审核可编辑；任何人不得新增正文段落。
- **设置层**：
  1. 角色层已保证：C 端贡献者不勾"更新全部"（§2.2），因此其只能改自己创建的页，改不了 A06；
  2. 书籍 A → Permissions → 确认"更新"动作只含 **临床审核、内容管理员** 两行；
  3. 若你的版本支持**页面级权限**（打开 A06 → 权限/Per-missions 标签，菜单名以你所装版本后台为准）：在 A06 单页上把更新权显式只留这两个角色，覆盖章节默认；不支持页面级权限的版本，以上两步即为全部措施。
- **验证生效**：用 C 端贡献者账号登录，打开 A06 → 页面上**看不到"编辑"按钮**；用临床审核账号登录 → **能看到编辑按钮但不能删除**；用读者账号 → 只能看不能编。

### 4.2 B 类案例页（书籍 B 全部情景案例叙事页）

- **要求**：仅内容管理员可创建；案例事实口径统一，避免多人各写各的案例。
- **设置层**：书籍 B → Permissions → "创建"动作只添加 **内容管理员** 一行（B 端编辑、C 端贡献者行均不勾创建）。
- **验证生效**：用 C 端贡献者账号登录进入书籍 B → 书籍首页与任何章节页**看不到"新建页面/New Page"按钮**；用内容管理员账号 → 按钮在。

### 4.3 18 条药品名壳页（类别：商品名 9 + 分子名 5 + 其他通用名 4；对应 `03_零用药系统配置\重定向页\` 下 18 个文件；其余 93 条通用词词条无壳页）

- **要求**：仅内容管理员可编辑；不进任何导航；正文固定只有一行 `#REDIRECT [兜底页链接] `。
- **设置层（三步法，按顺序做）**：
  1. **建组**：把 18 条药品名壳页全部集中挂在书籍 A 的"边界说明"章节下，**不在书籍首页、章节导航树之外单独挂链接**；A00 首页只保留一个指向 A06 的入口。**后台操作位置**：书籍 A → 页面列表/章节管理，逐条新建或把壳页移动进"边界说明"章节。**验收标志**：书籍 A 目录树与首页看不到这 18 条壳页条目（它们只挂在"边界说明"章节内）。
  2. **挂书籍权限**：书籍 A → Permissions（权限）→ Enable Custom Permissions（启用自定义权限）→ "更新 / 删除"动作只留 **内容管理员** 一行（临床审核在 A06 单页上按 §4.1 另开权限；药品名壳页不给临床审核编辑权——它们只是跳转壳，改错了无人需代劳）。**后台操作位置**：书籍 A → 右上角 Permissions 标签页。**验收标志**：书籍 A 权限矩阵里"更新 / 删除"动作行仅含内容管理员，无其他内容角色。
  3. **页面级覆盖**：若版本支持章节级权限，直接对"边界说明"章节设更新/删除仅内容管理员，覆盖章节默认继承（以你所装版本后台为准）；不支持章节级权限的版本，前两步即为全部措施。**后台操作位置**：书籍 A → "边界说明"章节 → Permissions/权限标签页。**验收标志**：用 C 端贡献者/B 端编辑账号打开任意一条药品名壳页，页面上无"编辑/删除"按钮。
- **验证生效**：
  - 导航验证：打开书籍 A 目录树与首页，看不到 18 条药品名壳页条目；
  - 权限验证：用 C 端贡献者/B 端编辑账号打开任意一条药品名壳页 → 无"编辑/删除"按钮；
  - 内容验证：抽查 3 条药品名壳页正文，确认仍只有那一行 `#REDIRECT`（详见 `巡检表_周月季.md` M2 月度全量核对 18 条）。

## 5. 权限变更后必须验证的 5 步（用另一个账号实际点一遍）

任何一次角色勾选 / 书籍权限改动后，**不要只看保存成功提示**，用下面三个测试账号实测（每个测试账号只测其对应角色那一份）：

1. **读者账号**：登录后应能打开书籍 A、B 任一页面；应**看不到**书籍 C、D 的任何链接，直接输 C/D 的 URL 应被拒；页面上看不到任何编辑/新建按钮；能点页面右下角导出按钮（A/B 书）。
2. **C 端贡献者账号**：能在书籍 A 新建草稿页；进入书籍 B 应无"新建页面"按钮；打开 A06 应无编辑按钮；打开书籍 C/D 应被拒。
3. **B 端编辑账号**：能打开书籍 C 并新建/编辑页面；书籍 D 应被拒（连看都看不到）；书籍 A 能编辑但不能删除任何页面。
4. **临床审核账号**：能打开 A06 并编辑；书籍 D 能新建/编辑；书籍 C 能编辑但不能新建。
5. **退出登录（Guest）**：直接访问 `https://<站点>/books/public-kb` 与 `.../books/family-tools` 应被引导到登录页；站内对未登录者不暴露任何页面标题。

> 任一步不符合预期，立即回后台对照本文件 §2–§4 复查勾选项，修正后把这 5 步再跑一遍；实测结果截图存入 `05_审核与运营\证据\权限验证\`（目录自行新建，按日期命名）。

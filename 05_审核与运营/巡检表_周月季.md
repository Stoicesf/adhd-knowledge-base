# 巡检表（每周 / 每月 / 每季度）

> 每项固定六栏：**检查项 ｜ 操作步骤（具体到搜什么词、看哪一页）｜ 通过标准 ｜ 不合格处置 ｜ 责任人 ｜ 证据留存方式**。
> 所有"证据"统一存 `05_审核与运营\证据\` 下按周期建子目录（`周检\2026-W45\`、`月检\2026-11\`、`季检\2026Q4\`），截图命名规则 = 检查项编号_日期.png；CSV/日志导出按项命名。
> 兜底系统实物对照：`..\03_零用药系统配置\`（关键词表 CSV/JSON、重定向页\、搜索页横幅注入片段.html、反馈区块片段.html、正式声明文本.md、配置说明.md）。

## 一、每周巡检（建议每周固定一个工作日执行）

### W1 抽检 5 个 C 端页面，查用药经验叙述

- **操作步骤**：内容管理员用随机数从书籍 A/B 全量页面里抽 5 个（滚动覆盖，本月不重复上周已抽过的页面）；逐页通读正文+评论区；重点看**案例页（B 类叙事页）与 FAQ 类段落**，检查是否出现"我家孩子吃了某种药之后……"式真实用药经验叙述、疗效描述、与干预联用增效暗示。
- **通过标准**：5 页正文与评论区均无任何真实用药经验叙述；评论区出现的此类留言已被折叠/回复引导至 A06。
- **不合格处置**：正文出现 → 立即按《退回改写单》下线该页改写；评论出现 → 删除评论并在当周反馈台账登记，反馈给该评论作者"请到 A06 查看本库边界"。
- **责任人**：内容管理员。
- **证据留存**：5 个页面抽检记录（页面名+结论）写入 `证据\周检\当周\抽检记录.md`；不合格页截图存档。

### W2 汇总"用药问题"反馈点击，识别高触发页面

- **操作步骤**：每周一导出/记录上周页面底部"这是一个用药问题"链接（反馈区块片段.html 内 `kb-fb-med` 按钮）的点击数据；按来源页面排序，列出点击 ≥1 次的页面清单。
- **通过标准**：所有点击都能在 24 小时内确认最终落点为兜底页 A06（配合月度重定向解析检查）；无反馈留言在站内得到药物展开回答。
- **不合格处置**：发现某页 48 小时内无人处置反馈 → 当周补齐；某页连续 3 周为高触发页 → 在月检 M4 中专项复查该页是否内容诱导了用药疑问。
- **责任人**：内容管理员。
- **证据留存**：每周反馈点击导出表（CSV 或后台日志截图）存 `证据\周检\当周\反馈点击.csv`。

### W3 全站禁用词扫描（周度快扫）

- **操作步骤**：用 `..\03_零用药系统配置\药物关键词表\药物关键词表.csv` 的 111 条词条（词表全量；其中仅 18 条药品名 `has_redirect=true` 建有壳页），在站内搜索逐个试搜（每周抽 10 条滚动覆盖）；同时对书籍 A/B 新发布页面全文做关键词命中检查。
- **通过标准**：**任何教育类正文页不得命中药名/剂量类词**；18 条药品名壳页命中后应自动落兜底页 A06，其余 93 条通用词条无壳页、由搜索横幅拦截（不得有教育正文页被命中）。
- **不合格处置**：正文页命中禁用词 → 立即下线，按《退回改写单》退回（原因类别=含禁用词）。
- **责任人**：内容管理员。
- **证据留存**：搜索结果页截图（每词 1 张）存 `证据\周检\当周\禁用词扫描\`。

### W4 评论区与新注册账号巡检

- **操作步骤**：扫一遍上周全部新评论；检查新注册账号的角色指派是否正确（无普通读者被误提权）。
- **通过标准**：新评论无广告/无用药咨询展开回复；新账号角色与申请用途一致。
- **不合格处置**：误提权立即降回并按《角色与权限配置表》§5 重跑 5 步验证。
- **责任人**：内容管理员（账号权限异常时知会 Admin）。
- **证据留存**：评论巡检记录 + 新账号清单截图存 `证据\周检\当周\评论与账号.md`。

## 二、每月巡检（每月最后一个工作日执行）

### M1 关键词全量站内搜索：确认命中只指向兜底页与固定声明

- **操作步骤**：打开 `..\03_零用药系统配置\药物关键词表\药物关键词表.csv`，按 `keyword` 列 111 条词条逐词在站内搜索（词表仍 111 条，供横幅匹配；其中仅 18 条药品名建有壳页）；逐词记录搜索结果第一屏。
- **通过标准**：每个词的搜索结果中，**展开讲药物的教育类正文页命中数 = 0**；分两层核对：**18 条药品名词条**（商品名 9 + 分子名 5 + 其他通用名 4）命中其壳页后应自动落 A06 兜底页；**其余 93 条通用词条无壳页**，结果顶部应出搜索横幅，条目只应有 A06（兜底页）+ 固定声明相关内容。
- **不合格处置**：发现教育正文页命中 → 同 W3 下线退回；药品名词未跳 A06 → 转 M2 排查壳页跳转链路；通用词条无横幅 → 转 Q4 复查横幅片段。
- **责任人**：独立复核人执行搜索，内容管理员复核结论。
- **证据留存**：111 条词条搜索结果截图压缩包存 `证据\月检\当月\M1搜索截图\`，加一份 `M1结论.csv`（每词一行：词条类别[药品名壳页18/通用词横幅93]/命中条目数/是否合格）。

### M2 逐条药品名壳页仍能解析到兜底页（必查项，每月全量核对 18 条）

- **操作步骤**：
  1. 从 `..\03_零用药系统配置\药物关键词表\药物关键词表.csv` 的 `redirect_page_slug`（即 `has_redirect=true`）列取 **全部 18 条药品名壳页 slug**（商品名 9 + 分子名 5 + 其他通用名 4），每月**全量逐条核对，不再抽样**；
  2. 逐个直接访问壳页 URL（形如 `/books/public-kb/page/<slug>`）；
  3. 观察浏览器落点。
  > 为什么改全量：壳页已从 111 条收敛为 18 条药品名（删 93 条通用词壳页），数量小、全量直接访问一遍成本很低；原"每月抽 10 条、约 11 个月轮完全量"的抽样口径不再必要，全量核对可当月覆盖全部壳页；且原"主词条页/变体页各抽一半"的变体页风险已随 93 条通用词壳页删除而消除。
- **通过标准**：18 条壳页逐条**自动跳转到兜底页** `medication-boundary` 并正常渲染声明全文。
- **"重定向失效"的典型表现（看到即判不合格）**：
  - 页面打开后**只显示一行 `#REDIRECT` 原文**（说明重定向解析没生效，壳被当成普通正文渲染）；
  - 跳转**跳到 404**（说明兜底页被移动/改名，或重定向里的链接指向了占位旧域名）；
  - 跳转后落在**空白页/报错页**。
- **不合格处置**：记录失效 slug 清单 → 对照 `..\03_零用药系统配置\配置说明.md` ②③ 节修复（正文行被改、或改域名后未重跑 `设置域名.py`），修复后重跑全部 18 条；当月修复无效则升级为当周 W3 加测。
- **责任人**：内容管理员。
- **证据留存**：全量清单 `M2壳页核对.csv`（slug/跳转落点/结论，18 行）+ 失效现场截图存 `证据\月检\当月\M2重定向\`。

### M3 检查 B 端转介页是否被加入药物内容

- **操作步骤**：打开书籍 C 的 C03 转介页与全部 C 书页面，通读；核对 C03 的固定话术是否仍为"不讨论药物选择"的边界句；另查书籍 C 是否被加入任何药物展开段落。
- **通过标准**：C 书全部页面中，`药物/用药/不良反应` 只出现在否定句/边界句；无药名、无剂量类词；C03 固定话术一字未动。
- **不合格处置**：改动即回滚（版本历史恢复），按《退回改写单》退回修改人。
- **责任人**：临床审核。
- **证据留存**：C03 页面全文截图 + 结论存 `证据\月检\当月\M3_C书边界.png`。

### M4 最后审核满 12 个月的 C 端页面清单

- **操作步骤**：导出书籍 A/B 全部页面，按元数据"最后审核"日期排序；筛出距今 ≥12 个月的页面。
- **通过标准**：超期页面 100% 被标记"待复核"并置顶（见 SOP §2.3）；**标记 ≠ 下线**。
- **不合格处置**：发现未标记的超期页 → 当天补标记并排期；发现有页面被擅自下线 → 恢复上线并在台账记一次流程违规。
- **责任人**：内容管理员。
- **证据留存**：超期清单 `M4待复核清单.csv`（页面名/最后审核日期/标记状态）存 `证据\月检\当月\`。

### M5 药品名壳页是否还需进一步收敛的观察项（仅观察，不强制处置）

- **操作步骤**：收敛后，"药、药物、用药、副作用、要不要吃药"这类通用词/问句已**不再命中任何壳页**，由搜索横幅兜底（实测见 `..\06_离线预览站\搜索实测结果.csv`）；本月起 M5 只观察 **18 条药品名壳页**（商品名 9 + 分子名 5 + 其他通用名 4）是否还在制造冗余：选 5 个高频药名词（商品名与通用名搭配选），逐词截图搜索结果第一屏，**数第一屏里有几条是 `med-*` 壳页**，同时登记当月这 18 条壳页的维护动作数（建/删/改次数），记入当月台账并与上月对比。
- **观察项（两个可观测指标，连续统计即可，无硬性"合格数"）**：
  1. **药品名壳页带来的搜索结果重复条目数**：第一屏 `med-*` 壳页条目数 > 3 条记为"偏高"；
  2. **维护成本**：当月 18 条壳页的实际维护动作（建/删/改）次数，以及因壳页跳转链路过期导致的 M2 不合格条数。
- **触发评估条件**：以上两个观察项之一**连续两个月**达到"偏高/异常"，才触发评估会——讨论是否把 18 条药品名壳页进一步合并/减页（例如商品名与分子名互相合并，或直接退化为"横幅拦截 + 单页兜底"；迁移步骤与前置比对见 `..\03_零用药系统配置\配置说明.md` 末节）。**谁拍板：评估结论由内容管理员 + 临床审核共同拍板，书面记录后执行**；未拍板前保持现状（18 条药品名壳页是当前已确认方案，巡检只盯着它的代价）。
- **责任人**：内容管理员统计，临床审核参与拍板。
- **证据留存**：5 词截图 + `M5药品名壳页观察.csv`（词/壳页数/当月维护动作数/是否偏高/环比）存 `证据\月检\当月\`。

## 三、每季度巡检（每季度末执行）

### Q1 复审角色权限，移除不活跃编辑账号

- **操作步骤**：导出全部非 Admin 用户清单；查近 90 天无任何编辑/评论动作的 C 端贡献者、B 端编辑账号；在角色列表逐项核对 §2 勾选是否与 `角色与权限配置表.md` 一致（防权限漂移）。
- **通过标准**：不活跃 ≥90 天账号已降回"读者"或停用；勾选清单与配置表逐项一致。
- **不合格处置**：权限漂移 → 按配置表回改并重跑该文件 §5 的 5 步实测；不活跃账号处理记录在案。
- **责任人**：内容管理员（账号操作请 Admin 配合）。
- **证据留存**：权限核对勾选表截图 + 账号处理清单 `Q1权限复审.csv` 存 `证据\季检\当季\`。

### Q2 按站内搜索日志补充关键词变体

- **操作步骤**：导出本季站内搜索日志，筛出**含"药"字或命中过兜底横幅**的查询词；与 `..\03_零用药系统配置\药物关键词表\药物关键词表.csv` 的 `keyword + variants` 列比对。
- **判定标准**：某新词**单季出现 ≥3 次**、且**未被现有 variants 列任何变体覆盖** → 判定为"待收新词"。
- **通过标准**：待收新词清单形成；处置顺序按 `配置说明.md`：先补词表与横幅内联数组 → 再（如需）补建该词重定向页。
- **不合格处置**：发现高频漏拦词（单季 ≥10 次）而未处理 → 季检内补完，并补一轮回归搜索。
- **责任人**：内容管理员。
- **证据留存**：搜索日志导出 + `Q2新词比对.csv`（查询词/出现次数/是否已覆盖/处置）存 `证据\季检\当季\`。

### Q3 书籍级权限矩阵与实际勾选漂移复查

- **操作步骤**：逐本打开 4 本书的 Permissions 标签页，截图，与 `角色与权限配置表.md` §3.2 的 20 格矩阵逐格比对；重点复查 C、D 两书的"Everyone Else"行仍为关闭。
- **通过标准**：20 格与矩阵完全一致；Guest 对 A/B 仍关闭（退出登录实测一次）。
- **不合格处置**：漂移即回改 + 重跑权限 5 步验证。
- **责任人**：内容管理员。
- **证据留存**：4 本书权限页截图 + 比对结论表 `Q3权限矩阵比对.md` 存 `证据\季检\当季\`。

### Q4 兜底"两条腿"配置完整性复查（横幅片段 + 反馈区块仍在位）

- **操作步骤**：① 检查 Settings → Custom HTML Head Content 中 `搜索页横幅注入片段.html` 内容仍完整在位（对照原文件哈希/全文比对）；② 抽 3 个 C 端页面，确认底部 `反馈区块片段.html` 仍被粘贴且链接指向现行域名；③ 用变体词（如"adhd药""專注達"）搜一次，确认横幅仍命中。
- **通过标准**：横幅片段无丢失/未被截断；反馈区块在 3 页均在位；变体搜索横幅命中。
- **典型失效表现对照**：搜"剂量"顶部无横幅（片段被缓存清掉或被覆盖）→ 重新粘贴片段并强刷缓存，按 `配置说明.md` ①节重来。
- **责任人**：内容管理员。
- **证据留存**：Custom HTML Head 框截图 + 变体搜索横幅截图存 `证据\季检\当季\Q4配置完整性\`。

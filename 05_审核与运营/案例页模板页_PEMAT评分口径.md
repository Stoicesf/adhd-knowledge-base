# 案例页 / 模板页 PEMAT-P 评分口径（第二批起执行）

> 本文件是《写作规范与证据分级标准》§7 与《C-PEMAT-P 发布门槛与评分规则》在"模板页 / 案例页"这两种页型上的**操作细则**。母文件管 24 条本身，本文件只管这两种页型怎么判 NA、怎么算分母、怎么处理案例页特有的"教学虚构标注"与"无勾选清单"。
> 与母文件冲突时，以母文件为准；母文件未细化的，以本文件为准。
>
> **硬规矩（v1.1）**：推演值必须标注"推演（非实际评分）"；推演值不写入 `页面清单状态表.csv`、不写入任何校验记录的结论段。页面写完后必须按实际正文重评，实际评分与推演值不一致时以实际评分为准。

## 0. 页型界定（先认页，再评分）

| 页型 | 识别特征（满足其一即为该页型） | 骨架依据 |
|---|---|---|
| 模板页 | 页面含至少一张"可打印 / 可照抄"的填空式表格或话术清单，字段带"例：……"示例；读者的主要动作是"填这张表 / 抄这段话" | 规范 §2.3 + B04 样例 |
| 案例页 | 页面含示范对话脚本或情景叙事段，元数据 `证据状态: 虚构教学案例`，或文首有 `> 本页人物与情节为教学虚构……` 标注；读者的主要动作是"照着练这段话" | 规范 §3.3 + B03 样例 |
| 解释页 / 可操作页 | 不属上述两类，按母文件 §7 通用规则评分 | 母文件 §7 |

> 一页同时含模板和案例（如"先给示范对话、再给填空表"）→ 按"**主体动作**"判：读者读完后主要要做的事是填表 → 模板页；主要要练对话 → 案例页。判定结果写在评分记录"备注"列。

## 2. 分母算法（写死）

```
实际分母 = 原分母 − 该页转 NA 条目数
```

- 原分母：可理解性恒为 17，可操作性恒为 7（母文件 §7.1 已锁定 24 条口径，不得按 23 条 / 16 条计）。
- 每页**必须**在评分记录"备注"列与本文件配套的校验记录里同时列出三元组：

```
可理解性：原分母 17 → 转 NA 条目（列编号，如 U14, U15, U16）→ 实际分母 14
可操作性：原分母  7 → 转 NA 条目（列编号，如 A5）           → 实际分母  6
```

- **禁止只报百分比**（如"可理解性 92%"）。只报百分比而不列三元组的记录视为无效，退回重填。
- 得分计算：`子量表得分(%) = 该子量表打 1 的条目数 ÷ 该子量表实际分母 × 100`。
- 门槛不变：两子量表均 ≥ 70%。

## 3. 禁止事项（清单 + 反例）

| # | 禁止项 | 反例（出现即判评分无效） |
|---|---|---|
| 3.1 | 不得为使分数过线把可判条目转 NA | 某模板页无任何插图，评分者把 U13（应记 0）也转 NA，理由写"本页不需要图"；这样 U 类分母从 14 缩到 13，同样的 12 分从 86% 变 92%，**分母缩水、分数虚高**。U13 / A7 在母文件中无 N/A 条件，永远不得转 NA |
| 3.2 | 不得因"页里没有表格 / 插图"就自动把 U14–U17 全转 NA | U14 / U15 看"视觉辅助（插图 / 流程图）"，U16 看"插图照片"，U17 看"表格"，三者**对象不同、判据独立**。一页可能"有表格但无插图"——此时 U17 适用打分，U14 / U15 / U16 才 NA；也可能"有流程图但无表格"——此时 U14 / U15 / U16 适用打分，U17 才 NA。**不许写一句"本页无图表"就把四条一锅端** |
| 3.3 | 每一条转 NA 必须配一句**页面事实依据** | 转 NA 记录必须形如：`U14=NA（依据：发布稿全文无 ![]() 图片、无 Mermaid 图，仅含 2 张 Markdown 表格与加粗列表，见"具体怎么做"节）`。不许只写"无视觉辅助"五个字 |
| 3.4 | 不得替作者脑补"这页本来就不需要 X" | 母文件 §4.2 评分纪律第 1 条：只依据发布稿可见内容。材料里没写 = 没有，记 0；不是"它本来不需要"，转 NA |
| 3.5 | 不得把引号台词误算进 A2 的"称呼你" | A2 看**作者对读者的叙述**是否用"你"。脚本里角色 A 对角色 B 说"你明天……"不算 A2 得分；正文叙述部分（"你下次可以这样开口"）才算 |

## 4. 案例页专项

### 4.1 "虚构教学案例"标注怎么计入可理解性

**判定结论（v1.0 写死）**：该标注**不单独占用 PEMAT 任何一个条目**，但作为 **U1（材料目的完全明确）与 U2（不含偏离目的内容）打 1 的事实依据之一**。

| 处理方式 | 说明 |
|---|---|
| 标注形式 | 规范 §3.3 要求的文首一行：`> 本页人物与情节为教学虚构，用于说明方法，不代表任何真实个案。`（或元数据 `证据状态: 虚构教学案例`） |
| 计入哪条 | U1：读者读完前两行即知"这是教学示范脚本，不是真实个案报告"——目的被明确告知；U2：标注把"虚构"挑明，读者不会把台词当成真实疗效断言，材料不偏离"示范对话"这一目的 |
| 不做什么 | 不新增一条"U18 教学诚信"；不因为"标了虚构"就把 U3 / U5 / U11 等本来打 0 的条目抬成 1；不在打分表之外另加"诚信加分" |
| 为什么不会被用来刷分 | ① 该标注是规范 §3.3 **强制要求**（情景叙事页必须加，不加即按 §9.6 退回），不是作者可选择性添加的加分项；② 它只影响 U1 / U2 这两条的"事实是否成立"判断，而 U1 / U2 本来就要打——标注是把"读者是否清楚目的"这件事的证据补全，不是多送一分；③ 没标注的案例页反而要按规范退回，不存在"加这行能涨分"的套利空间 |

### 4.2 案例页可操作性 A1–A7 怎么判

案例页通常没有 ☐ 勾选清单，也没有填空表格。判据如下：

| 条目 | 判据（案例页专用） | 反例（错误判法） |
|---|---|---|
| A1 | 页面是否有"今天能做的 3 件事"或脚本末尾"下次你可以这样开口"式行动指引 → 有打 1，纯故事打 0 | 把"案例里没有 ☐ 清单"直接判 A1=0 是错的——A1 只问"有没有行动"，不问行动形式 |
| A2 | **看叙述部分**（非引号台词）是否用"你"称呼读者；正文叙述用"你"打 1，整页都是对话、叙述部分无"你"打 0 | 把"脚本里角色没叫对方'你'"当作 A2=0 是错的——角色对话不算 |
| A3 | 脚本是否分"第 1 步 / 第 2 步 / 第 3 步"或有明确的阶段划分（承认事实 → 给安全感 → 重设规则）→ 有打 1，纯线性流水账打 0 | 把"案例里没有 ☐ 勾选清单"判 A3=0 是错的——步骤可以是话术的三段式，不一定要勾选项 |
| A4 | 脚本是否提供了"可直接照抄的话术块"（带引号、可整段复制）→ 有打 1；纯故事无任何可复制文本打 0 | 把"没有填空表格"判 A4=0 是错的——话术块本身就是工具（见 B03 三步台词） |
| A5 | 按 §5.1 通用判据。案例页一般无计算 → 转 NA | — |
| A6 | 页面若有"误区对照表"，看它是否被用作"行动工具"（如"照着这张表避免再犯错"）→ 是打 1；若表格只是对照展示、未说明怎么用它行动 → 打 0；无表格才转 NA | 把"案例里没有行为记录表"直接判 A6=NA 是错的——误区表也是表格，有表就要判，不能 NA |
| A7 | 母文件无 N/A 条件。无插图打 0 | — |

> **核心原则**：案例页的"可操作"指"读者能照着这段话去说 / 去做"，不是"读者能照着填一张表"。把"案例里没有 ☐ 清单"直接判 A2 / A3 / A4 = 0 属于误判，必须退回重评。

### 4bis.2 边界声明页可操作性 A1–A7 怎么判（反例警告）

边界声明页通常**没有 ☐ 勾选清单，也没有填空表格**。判据写死：

> **达标口径**：以"读者读完知道自己该做什么、不该做什么、该找谁"为可操作达标——**不是靠有没有 ☐ 清单**。

| 条目 | 边界声明页专用判据 | 反例（错误判法） |
|---|---|---|
| A1 | 读者读完是否清楚"该做什么（带结果去门诊）、不该做什么（别自行停药 / 加药 / 据题自诊）、该找谁（儿童精神科 / 心理科）"→ 有出口打 1，只声明"不是诊断"无出口打 0 | **把"边界声明页没有步骤清单"直接判 A1–A7 全 NA 是错的**——会让可操作性 7 条分母归零，整页可操作性无法计分 |
| A2 | 叙述部分（非引用块内的固定话术）是否用"你"称呼读者；边界声明页常出现"你可以把结果带给医生"即打 1；通篇第三人称"该工具仅用于筛查"无"你" → 打 0 | 把"声明页里没有角色对话"当作 A2=0 是错的——A2 看作者对读者的叙述，不需要对话 |
| A3 | 行动是否被拆成"该做 / 不该做 / 找谁"三段或"第一步 … 第二步 …"→ 有划分打 1；只有一句笼统"请就医"打 0 | 把"声明页里没有 ☐ 勾选清单"判 A3=0 是错的——"该做 / 不该做 / 该找谁"本身就是步骤划分 |
| A4 | 页面是否给了可照抄的工具（"就诊时要问医生的 3 个问题"清单、可打印的结果摘要模板）→ 有打 1；纯声明无可复制文本打 0 | 把"声明页里没有填空表格"判 A4=NA 是错的——A4 母文件无 N/A 条件，没工具就打 0，不 NA |
| A5 | 无计算要求 → NA（依据：全文无计算要求） | — |
| A6 | 有对照表 → 看它是否被用作"行动工具"；无表格 → NA | — |
| A7 | 无图示 → 记 0，不 NA | — |

> **红线**：**把"没有步骤清单"直接判整页可操作性不适用（A1–A7 全 NA）是错的**。母文件 §7.2 对 A1–A4、A7 的 N/A 条件均为"无"，页型不是 NA 依据；这样做会让可操作性 7 条分母归零，违反 §3.1 与 §7 分母过小处置。

### 4ter.2 解释页可操作性 A1–A4 是否可整体转 NA？——写死规则

> **结论（v1.1 写死）：不可以。A1–A4 不得因"本页是解释页"整体转 NA。**

理由：

1. **母文件 §7.2 对 A1、A2、A3、A4 的 N/A 条件均为"无"**——与 U13、A7 同类，页型不是 N/A 依据。PEMAT 的 N/A 只给"客观上不存在该类内容"（无数字、无表格、无插图、无计算、极短材料），不给"这页本来就不打算可操作"这种主观判断。
2. **解释页若通篇纯机制解释、无任何行动出口，A1–A4 全部记 0（不是 NA）**——这是真实扣分，反映"这页确实不可操作"。把它们转 NA 会让可操作性分母从 7 缩到 3（只剩 A5、A6、A7 可判），属于 §3.1 禁止的"为使分数过线缩水分母"。
3. **解释页过不了 70% 门槛是正常信号**——规范 §2.3 要求每个 C 端页面第一节就是"今天能做的 3 件事"；一个纯解释页在可操作性上拿低分，说明它缺了规范强制的行动出口，应退回补"下一条可操作建议"（指向库内另一页），而不是靠 NA 把分母缩没。
4. **A5、A6 仍按客观条件判 NA**：无计算 → A5 NA；无表格 → A6 NA。这两条与页型无关，全文事实说话。

| 条目 | 解释页判据 | 反例 |
|---|---|---|
| A1 | 末尾是否给了"下次遇到 X，你可以先做 Y"或指向另一页的行动出口 → 有打 1；纯解释打 0 | 因"这页是解释页"把 A1 转 NA → 错 |
| A2 | 叙述部分是否用"你"称呼读者 → 用了打 1；通篇第三人称打 0 | 因"解释页不描述行动"把 A2 转 NA → 错 |
| A3 | 是否有"先观察 / 再尝试"式最小步骤 → 有打 1；纯解释打 0 | 因"解释页没有 ☐ 清单"把 A3 转 NA → 错 |
| A4 | 是否给了可照抄的工具（自检清单 / 一页纸）→ 有打 1；纯解释打 0 | 因"解释页没有模板"把 A4 转 NA → 错 |
| A5 | 无计算 → NA（依据：全文无计算要求） | — |
| A6 | 无表格 → NA；有表但纯对照未说怎么用 → 打 0 | — |
| A7 | 无图示 → 记 0 | — |

## 5. 模板页专项

### 5.1 A5（计算类）怎么判

| 页面事实 | A5 判定 |
|---|---|
| 模板只要求填文字 / 划线空格（如"孩子姓名＿＿""具体场景 1：＿＿"），读者**不需要做任何运算** | 转 NA（依据：模板字段均为开放文本，无数值换算要求） |
| 模板含"发生频率：每周大约几天出现"等纯记录字段，读者只填数字、**不要求累加 / 求比** | 仍转 NA（不是计算，只是记录） |
| 模板含"每周离座次数 × 周数 = 月累计""作业完成率 = 完成题数 ÷ 总题数"等**需读者做乘法 / 除法 / 百分比换算** | 适用。此时再看：是否给了计算示例（如"例：每周 3 次 × 4 周 = 12 次 / 月"）→ 有示例打 1，无示例打 0 |
| 模板本身就是"行为记录表"，要求家长逐次打勾后**自己数总数** | 适用。若页面写了"每周统计一次总数"但没给计数示例 → 打 0 |

### 5.2 模板页可操作性达标标准："能填、能照用"

**写死标准**：模板页在 A1–A4、A6、A7 上是否达标，以以下三条**全部满足**为准：

1. **字段无歧义**：每个"项目"列都写明了要填什么（如"具体场景 1：什么时候、在哪里、发生了什么"），不留"情况说明"这类空泛栏；
2. **有填写示例**：至少一栏给了一行"例：……"示范（参照 B04 家长端模板），不是空表；
3. **能直接打印 / 照抄**：表格在 Markdown 导出后行列对齐、下划线空格可手写或电子填写，读者不需要再改版式。

三条全满足 → A4 打 1；缺任一条 → A4 打 0。

**与"有步骤清单"的区别**：

- A3 看的是**行动本身是否分步骤**（模板页的步骤是"今晚填这张表 → 打印两份 → 约 15 分钟面谈"，见 B04"今天能做的 3 件事"），不是表格内部有几行；
- A4 看的是**表格本身能不能直接拿来用**（字段 + 示例 + 可打印），不是有没有"步骤 1 / 步骤 2"；
- 一个模板可以步骤清晰（A3=1）但表格空泛无示例（A4=0），反之亦然。两条独立打分。

## 7. 分母过小的处置（写死）

**触发条件**（任一子量表命中即触发）：

```
可理解性：实际分母 ≤ 10（原分母 17 × 60% = 10.2，向下取整）
可操作性：实际分母 ≤ 4（原分母  7 × 60% =  4.2，向下取整）
```

**强制动作**：必须在该页的校验记录里**显式**写明一句——"该页是否仍适合用 PEMAT-P 评分"及理由，**不许沉默带过**。两种合规处置示例：

| 处置 | 写法示例 | 适用情形 |
|---|---|---|
| **仍适合用 PEMAT-P 评分** | "本页可理解性实际分母 11（转 NA：U14、U15、U16），仍 > 10。缺的三条均为'本页客观上无插图 / 流程图'，属于 PEMAT 官方 N/A 条件，非人为缩水；两子量表得分仍可与其他页横向比较。继续按 70% 门槛判定。" | 转 NA 的条目全部命中母文件 §7.2 列明的客观 N/A 条件（无数字、无表格、无插图、极短材料、无计算），且每条都有 §3.3 要求的页面事实依据 |
| **不适合，改用逐节人工复核** | "本页可操作性实际分母 3（转 NA：A5、A6、A7），≤ 4。转 NA 后样本量过小，70% 门槛在 3 条样本上波动 1 条即 ±33%，门槛失去区分力。本页改用逐节人工复核：对照规范 §2.3 骨架逐节检查（是否有'今天能做的 3 件事'、是否称'你'、是否分步骤、是否给工具），并在备注里说明'不适用 PEMAT-P 子量表得分、已改人工复核'。" | 转 NA 条目数过半，或转 NA 判据中混入了"这页本来就不需要 X"式主观判断（违反 §3.4），或两子量表实际分母都 ≤ 阈值 |

> 沉默带过（只在 CSV 里填数字、不写是否仍适合）视为评分记录不合格，按退回清单重填。

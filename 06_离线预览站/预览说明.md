# 离线预览站 · 使用说明

这是 ADHD 知识库内容包的**离线结构预览**：双击 `index.html` 即可在浏览器打开，**全程不需要联网**。
用途：在真正部署 BookStack 之前，先看书籍结构、页面样式、元数据徽章与搜索兜底逻辑长什么样。

## 怎么打开

直接双击 `index.html`（Windows 会用默认浏览器打开，`file://` 协议即可，不要用本地服务器）。

## 怎么重新生成

```
cd F:\ADHD文献\06_离线预览站
python 生成预览站.py
```

- 只依赖 Python 3 标准库，不需要 pip 装任何东西。
- 脚本扫描 `..\02_内容包\` 下 19 个 md，重新渲染并**覆盖**本目录的 `index.html`，可重复运行、结果幂等。
- `..\01_规范与标准\`、`..\02_内容包\`、`..\03_零用药系统配置\` 都是只读，脚本不会改它们。

## 这个预览站能看到什么

1. **三级层级**：左侧边栏 4 本书 → 章节 → 19 个页面，点击切换。C 本书标「仅 B 端角色可见」、D 本书标「仅临床角色可见」。
2. **首页 6 个高频入口卡片**：与 A00 / 规范 §8 一致，正好 6 条，显示目标用户与落点，点击直达第一落点页。
3. **每页顶部元数据条**：面向、证据状态四档彩色徽章（强证据=绿 / 有条件推荐=黄 / 经验性策略=蓝 / 虚构教学案例=红）、最后审核日期、零用药勾选条。
4. **「模板字段说明」面板**：C 端模板与 B 端模板字段清单；B 端含「本页不讨论药物选择与剂量 + 家长询问用药时的固定回应」。
5. **搜索演示**（本地浏览器内完成，不联网）——**两档分级**：
   - 输入普通词（作业 / 老师 / 记录表）→ 结果列表显示命中页面标题、所属书籍章节与摘要；**不出横幅、不出跳转**。
   - 输入通用词（剂量 / 副作用 / 要不要吃药 / 药物）→ 结果区**顶部出现黄色横幅**（可点 × 关闭），并显示蓝色说明条「ℹ 通用词不设独立页面，由横幅统一兜底」；**不出现任何"已重定向/跳转"字样**。
   - 输入药品名壳页词（专注达 / 择思达 / 哌甲酯 / 利他林 / 可乐定 / 托莫西汀 / 胍法辛 / Adderall 等 18 条）→ 横幅 + 红色可点击跳转条「➜ 该词在实站会跳转到用药兜底页（A06）（点击直达 A06）」，点击直达 A06。
6. **首屏「这个包怎么用」落地页**：说明这是离线预览、真实部署用 04 目录、内容以 02 目录为准。

## 预览站与 BookStack 实站的差异

| 维度 | 本预览站 | BookStack 实站 |
|---|---|---|
| 形态 | 单个 `index.html`（HTML/CSS/JS 全内联），双击即开 | 服务端应用，多页面 + 数据库 |
| 联网 | 完全离线，零外部资源（无 CDN / 外网字体 / 外链脚本） | 需要服务器与域名 |
| 登录与权限 | 无登录；C/D 书只做了「可见性提示」标签，实际人人可读 | 按角色登录，C/D 书对 C 端隐藏 |
| 搜索 | 前端 JS 子串匹配的**本地模拟**，只覆盖本预览的 19 页 | BookStack 全文索引搜索 |
| 药物兜底 | 前端命中 111 条词即弹横幅；其中 18 条药品名额外弹跳转条（模拟） | 03 目录的 18 条重定向壳页 + 搜索横幅注入片段，真重定向 |
| 页面 URL | 无 URL，全部是单页内 JS 切换 | 真实 books/…/page/… 路由 |
| 引用链接 | 出处里的 nice.org.uk / pmc 链接保留为可点文本（新窗口打开，rel=noopener），离线时只是点不出去 | 可正常访问 |
| 编辑 / 历史 / 附件 | 无 | BookStack 自带 |

### 一个已知的预览差异（不用改，仅说明）

在预览站搜索「剂量」时，结果里会出现 C01 / C02 / C03。原因：这三页的 B 端固定回应框里按规范必须出现「本手册不讨论药物选择与**剂量**」这句话，所以正文命中了该词。在 BookStack 实站里，书籍 C 仅 B 端角色可见，C 端用户根本搜不到这几页；本预览站只做了「仅 B 端角色可见」的徽章提示、并未真正隐藏，因此看起来像「前台也能搜到」——这是预览的模拟简化，不是内容错误。

## 测量环境声明（重要）—— 预览站本地检索模拟（非真实 BookStack 站内搜索）

> 四项声明、分词口径、效力边界、部署后观察项详见同目录 [`搜索实测口径说明.md`](搜索实测口径说明.md)。

本轮「搜索」**不是 BookStack 实站搜索**，也不是生产环境检索。它是：

- **执行方式**：`Node v22.23.2`（Python 3.13.16 仅用于生成 CSV）在本地 eval 内嵌 JS，用最小 DOM stub 触发 `doSearch()`；
- **匹配口径**：本地**子串匹配**——`toLowerCase()` 后 `indexOf(q)`，去首尾空格；**不是分词检索**；
- **搜索索引**：仅 19 个内容页（`02_内容包`），**不含 18 条壳页**；
- **与真实 BookStack 的差异**：BookStack 用 **ICU 分词**，分词边界、停用词、词干还原都会改变命中集；本地子串匹配与 ICU 分词**行为不会完全一致**，因此本地结果只能作**近似证据**，不能当真实检索行为的证据；
- **结论措辞**：本轮只能写"**本地模拟近似通过**"，不得表述为"实测通过""已验证"。

### 两条部署后口径（不要并入本轮通过结论）

- `0/10` 之类的壳页占比只能作为**近似证据**；真实数据写入"部署后验收清单"，等有 BookStack 实例再补。
- 18 条药品名壳页在真实 ICU 分词下是否仍会出现在无关查询的前 10 条，**本地模拟证明不了**——列为"部署后观察项"。
